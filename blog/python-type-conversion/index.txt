1d:T371a,<span id="一概述" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-一概述">（一）概述：</h3>
<p>在某些情景下，我们需要对数据内置的类型进行转换，以使其能够参与某些运算/进行某些输出和分析。</p>
<p>数据类型的转换分为显式（自动）和隐式的类型转换，隐式的可以自动完成，显式的需要使用类型函数。</p>
<p>类型函数内无参数时创建的是各类型所对应的空值。</p>
<span id="二隐式类型转换" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-二隐式类型转换">（二）隐式类型转换：</h3>
<p>隐式类型转换主要发生在Number数字的数据类型中（因其内部有不同类型的数据），当两个不同类型的数据进行运算时，默认向更高精度转换。</p>
<p>数据类型的精度由低到高依次是：bool int float complex</p>
<p>各种类型的隐式转换如下：</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code># bool->int
a1 = 99+True
b1 =False+10
print(a1)
print(b1)
# bool->float
a2 = 3.14+False
b2 = True+9.9
print(a2)
print(b2)
# bool->complex
a3 = 3+4j +True
b3 = False +5j
print(a3)
print(b3)
# int->float
aa1 = 5+3.14
bb1 = 10*8.88
print(aa1)
print(bb1)
# int->complex
aa2 = 3+(4.5+2j)
bb2 = 1.1j+3
print(aa2)
print(bb2)
# float->complex
aaa = 3.14159+(6.28+9.99j)
bbb = 4j+5.5
print(aaa)
print(bbb)
# 运行结果：
# 100  int 
# 10   int
# 3.14 float
# 10.9 float
# (4+4j) complex
# 5j   complex
# 8.14 float
# 88.80000000000001 float
# (7.5+2j) complex
# (3+1.1j) complex
# (9.42159+9.99j) complex
# (5.5+4j) complex
</code></pre></div>
<span id="三显式类型转换" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-三显式类型转换">（三）显式类型转换：</h3>
<span id="1-int将其他类型转换为整型" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-1-int将其他类型转换为整型">1. int()将其他类型转换为整型：</h4>
<ul>
<li>
<p>形式：<em><strong>int(x, base=10)</strong></em></p>
</li>
<li>
<p>允许的x范围类型：字符串、浮点数、布尔值，base是进制数，默认为十进制。</p>
<ul>
<li>浮点型转换为整型，直接舍去小数部分。</li>
<li>布尔值转换为整型，True为1，False为0。</li>
<li>字符串转换为整型，仅有纯整型字符串可以转换（即使是浮点型也不可以）。</li>
</ul>
</li>
<li>
<p>base仅允许在x为纯数字和纯整型字符串的情况下才可以指定，否则报错。</p>
<p>当字符串对应的纯整型字符串为k进制时，应当将base指定为k进制的形式。</p>
<p>如果base指定的k进制和字符串存储的数字无法对应（比如base中k=2但字符串出现0和1以外的数字），则报错。</p>
</li>
</ul>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>print(int(3.14))
print(int(True))
print(int("123456"))
print(int("101010",2))
print(int("aaac",16))
#输出结果：
# 3
# 1
# 123456
# 42
# 43692
</code></pre></div>
<span id="2-float将其他类型转换为浮点型" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-2-float将其他类型转换为浮点型">2. float()将其他类型转换为浮点型：</h4>
<ul>
<li>形式：<em><strong>float(x)</strong></em></li>
<li>允许的x范围类型：字符串、布尔值和整型。
<ul>
<li>整型转换为浮点型，后面+.0</li>
<li>布尔值转换为浮点型，True为1.0，False为0.0。</li>
<li>字符串转换为浮点型，只有纯整型字符串（十进制）和纯浮点型字符串可以转换（含小数点，小数点位置任意），其他均不可以。</li>
</ul>
</li>
</ul>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>print(float(3))

<span id="3-complex将其他类型转换为复数类型" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-3-complex将其他类型转换为复数类型">3. complex()将其他类型转换为复数类型：</h4>
<ul>
<li>
<p>形式：<em><strong>complex(real, imag=0)</strong></em></p>
</li>
<li>
<p>允许的real和imag类型：字符串、布尔值、整型和浮点型。</p>
<ul>
<li>整型转换为复数类型，为 (整型数+0j)。</li>
<li>布尔值类型转换为复数类型，True为 (1+0j)，False为 (0j)</li>
<li>浮点型转换为复数类型，为 (浮点数+0j)</li>
<li>事实上，前面三个可以组合输入两次作为 (输入参数1,输入参数2j)转换。</li>
<li>字符串类型转换为复数类型，只能为一个参数传入，可以是纯整型字符串和浮点型字符串，也可以形如 i +j 形式或者 i-j 形式</li>
</ul>
</li>
</ul>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>print(complex(123,2))

<span id="4-bool将其他类型转换为布尔类型" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-4--bool将其他类型转换为布尔类型">4.  bool()将其他类型转换为布尔类型：</h4>
<ul>
<li>形式：<em><strong>bool(x)</strong></em></li>

<li>空列表[]</li>
<li>空元组()</li>
<li>空字典{}</li>
<li>空集合set()</li>
<li>python关键字None</li>
</ul>
</li>
</ul>
<p>不再一一列举（有兴趣的自己去试试）。</p>

<span id="9-dict将其他类型转换为字典类型" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-9-dict将其他类型转换为字典类型">9. dict()将其他类型转换为字典类型：</h4>
<p>在说明dict的类型转换前，需要说明容器和多级容器的概念：</p>
<span id="容器" class="legacy-anchor" aria-hidden="true"></span><h5 id="section-容器">容器：</h5>
<p>Python中，可包含其他对象的对象，称之为“容器”。容器是一种数据结构。</p>
<p>常用的容器主要划分为两种：序列（如：列表、元祖等）和映射（如：字典）。序列中，每个元素都有下标，它们是有序的。映射中，每个元素都有名称（又称“ 键 ”），它们是无序的。</p>
<p>除了序列和映射之外，还有一种需要注意的容器——“ 集合 ”。</p>
<span id="多级容器" class="legacy-anchor" aria-hidden="true"></span><h5 id="section-多级容器">多级容器：</h5>
<p>在一个容器中嵌套一个容器，这个容器就叫二级容器；在被嵌套的容器中可以再嵌套容器，最外层的容器就叫做多级容器......由此可以获得多级容器。</p>
<p>多级容器不包括字符串，字符串是特殊的容器，任何字符在字符串中都是字符串的一个单独元素；</p>
<p>容器的类型取决于最外层的容器，不同的类型容器可以相互嵌套，但是，集合和字典除外；因为字典的键和集合中的值必须是可哈希的类型，即可变数据类型。</p>
