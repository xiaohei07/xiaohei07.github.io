（一）动态联编：

1. 概念：

动态联编是根据调用时对象的实际类型，选择相应的虚函数实现，也称晚期联编。这里讲的是语言规定的调用行为；编译器如果能够确定目标，也可能把调用优化为直接调用。

通过指针或引用调用虚函数时，可以体现这种动态选择。显式写出类名的限定调用（如 p->Base::fun()）会抑制虚调用。

2. 使用：

可以通过基类指针或引用调用虚函数，调用目标由对象的实际类型决定。派生类可以重写虚函数，也可以直接继承基类已有的实现；没有重写时，会使用继承的版本。这里的基类转换还要满足可访问、无歧义等条件。

3. 优点：

调用方可以使用统一的基类接口处理不同派生类对象。虚调用可能增加间接调用等开销，具体影响还取决于实现和编译器优化。

（二）虚函数：

1. 概念：

虚函数是在类中使用 virtual 声明的非静态成员函数。派生类对它进行重写后，通过基类接口调用时可以执行派生类版本。

virtual 写在类内的成员声明中；在类外给出函数定义时不再重复写。

派生类中符合重写条件的函数仍然是虚函数，即使省略 virtual。仅仅函数名相同还不够，参数列表、成员函数的 cv 限定和引用限定等也必须符合重写规则。C++11 起可以使用 override 让编译器检查。

普通虚函数不要求每一层派生类都重写，继承的实现可以继续使用。

  • 虚函数重写：派生类声明与基类虚函数对应的成员函数。函数名、参数列表及成员函数的限定条件需要匹配；返回类型通常相同，也可以满足协变返回类型的规则。析构函数的重写由析构函数自身的规则确定。

    协变返回类型：重写函数可以返回更具体的类类型指针或引用。例如基类函数返回 Person*，派生类函数返回 Student*，且 Student 公开、无歧义地派生自 Person。这仍然是重写；返回类型还须满足对应的指针/引用类别及 cv 限定要求。

    重写的访问限定符可以不同。

    除合法的协变返回类型外，不能只改变返回类型来重写基类虚函数。

    只有函数名相同、参数列表等不匹配时，派生类声明可能隐藏基类的同名函数，但不会取消基类函数原有的虚特性。

  • 隐藏：不局限于虚函数，但需要和虚函数概念结合理解。

    隐藏是指派生类的函数屏蔽了与其同名的基类函数。

    如果派生类的函数与基类的函数同名，但是参数不同。此时，不论是否为虚函数，基类的函数将被隐藏（注意不是重载，重载是在同一个类中发生）。

    如果派生类的函数与基类的函数同名，并且参数也相同，但是基类函数没有virtual 关键字。此时，基类的函数被隐藏（注意不是重写，重写有virtual关键字）。

——在参数及其他限定条件可比较的简单情形下，可以这样区分；下面的 virtual 指基类函数是否为虚函数：

  1. 签名匹配、基类函数为虚函数：重写；
  2. 签名匹配、基类函数非虚：隐藏；
  3. 参数不同、基类函数为虚函数：隐藏，不构成重写；
  4. 参数不同、基类函数非虚：隐藏。

2. 限制：

  • 虚函数必须是非静态成员函数。友元非成员函数、全局函数不能声明为虚函数；一个类即使暂时没有派生类，也可以声明虚函数。

  • 静态成员函数不能是虚函数，因为静态成员函数不受限于某个对象。

  • 虚函数可以声明为 inline。是否把某一次调用实际展开，由编译器决定，不能单凭 inline、对象调用或指针调用就断言一定内联或一定不内联。

  • 构造函数不能是虚函数：

    C++ 不允许把构造函数声明为虚函数。创建对象时选择构造函数，随后按规则构造基类和成员子对象；构造期间的虚函数调用还有下述限制。

  • 析构函数可以是虚函数。需要通过基类指针删除派生类对象时，本文这种普通 delete 用法要求基类有虚析构函数。

    基类析构函数是虚函数时，派生类析构函数也保持虚特性，无须重复写 virtual。通过基类指针删除派生对象，会先执行派生类析构函数，再依次析构其成员和基类。

    构造或析构期间，如果对正在构造或析构的对象调用虚函数，调用的是当前构造函数或析构函数所属类中的最终重写版本，不会分派到更下层的派生类。这个规则不能解释成“虚析构函数仍是静态联编”。

  • 不建议把赋值运算符重载作为虚函数。

3. 工作原理：

常见实现使用虚函数表（vtable）和虚表指针（vptr）完成虚调用：对象保存相关表指针，表中记录该类型的虚函数入口，调用时据此选择实现。派生类重写函数后，对应入口使用重写版本；未重写时可以继续使用继承的实现。

这是实现层面的理解方式。具体有几个表指针、放在对象的什么位置、表中还有哪些信息，由 ABI（应用二进制接口）及继承结构决定。例如 Itanium C++ ABI 的虚表布局 就有具体规则。不能把“总在第一个数据成员之前”“每个对象固定多出 8 字节”推广为 C++ 规则。

虚表、对象中的相关指针以及间接调用可能带来存储和执行开销。对象大小还包含对齐填充，调用也可能被优化；下面用 sizeof 观察当前环境的结果。

4. C++11 override && final

C++11新增了两个关键字override和final。

被override修饰的虚函数，编译器会检查这个虚函数是否重写。如果没有重写，编译器会报错。

用final修饰的虚函数无法重写。用final修饰的类无法被继承。final像这个单词的意思一样，这就是最终的版本，不用再更新了。

5. 表现：

  • 通过基类指针调用基类和派生类中的同名虚函数时:

    1. 若该指针指向一个基类的对象，那么被调用的是基类的虚函数；
    2. 若该指针指向派生类对象，调用该派生类中的最终重写版本；如果它没有重写，就使用继承的版本。

    这种机制就是实际上的“多态”——调用哪个虚函数，取决于指针对象指向哪种类型的对象。

  • 通过基类引用调用基类和派生类中的同名虚函数时:

    1. 若该引用引用了一个基类的对象，那么被调用的是基类的虚函数；
    2. 若该引用绑定派生类对象，调用该派生类中的最终重写版本；如果它没有重写，就使用继承的版本。

    调用哪个虚函数，取决于引用绑定的实际对象类型。

6.代码：

  • 一般情况的函数的虚函数重写，发生了动态联编（各种错误也在其中）：

    text
    #include<iostream>
using namespace std;
class Person
{
	//不允许对友元函数使用virtual
	//virtual friend void fun();
public:
	//如果下面的静态数据成员和成员函数被声明,不允许加virtual,必须去掉
	//static int i;
	//virtual static void addi(){}
	
	//不能对构造函数加virtual,必须去掉
	//virtual Person() {}

	//一般虚函数声明
	virtual void fun()
	{
		cout << "Person->fun()" << endl;
	}
	
	//内联虚函数；是否实际展开由编译器决定
	inline virtual void fun2()
	{
		cout << "Person->fun()2" << endl;
	}
	//不被允许的操作:仅改变返回类型,编译器无法区别。
	//virtual int fun()
	//{
	//	cout << "Person->fun()" << endl;
	//}
};
//不能对全局函数使用virtual
//virtual void fun(){}
class Student:public Person
{
public:       
	virtual void fun()//子类重写父类虚函数
	{
		cout << "Student->fun()" << endl;
	}
	//重写内联虚函数；inline 不保证调用一定展开
	inline virtual void fun2()
	{
		cout << "Student->fun()2" << endl;
	}
};
class Teacher:public Person
{
public:      
	void fun()//子类重写父类虚函数,不加virtual但编译器默认其为虚函数
	{
		cout << "Teacher->fun()" << endl;
	}
	//这个带参数的重载不重写基类的 fun()，自身也未声明为虚函数
	//上面的无参 fun() 仍然保持虚特性
	void fun(int)
	{
		cout << "Person2->fun()" << endl;
		return;
	}
};
class GoodStudent :public Student 
{
	virtual void fun()//子类重写父类虚函数
	{
		cout << "GoodStudent->fun()" << endl;
	}
};
class GoodTeacher :public Teacher
{
	void fun()//子类重写父类虚函数,不加virtual但编译器默认其为虚函数
	{
		cout << "GoodTeacher->fun()" << endl;
	}
};
int main()
{
	Student s;
	GoodStudent gs;
	Teacher t;
	GoodTeacher gt;
	Person* p = &s;
	//基类指针指向派生类,因为虚函数的声明,所以调用的是派生类的重写虚函数。
	p->fun();
	//对象类型在此处明确，但是否内联仍由编译器决定
	s.fun2();
	//按虚调用语义选择 Student::fun2；是否优化不能只看指针写法
	p->fun2();
	p = &t;
	//同p->fun();
	p->fun();
	p = &gs;
	//调用GoodStudent的重写虚函数
	p->fun();
	p = &gt;
	//调用GoodTeacher的重写虚函数
	p->fun();
	Student* ps = &gs;
	//派生类Student指针指向其派生类GoodStudent,调用GoodStudent的重写虚函数
	ps->fun();
	Teacher* pt = &gt;
	pt->fun();
	pt->Teacher::fun();//访问限定符可以不同,强制执行Teacher的fun函数

	cout << endl;
	//基类引用引用派生类,和指针效果相同。
	//注意引用一经确定对象后就无法修改了
	Person& cp1=s;
	cp1.fun();
	cp1.fun2();
	Person& cp2 = t;
	cp2.fun();
	Person& cp3 = gs;
	cp3.fun();
	Person& cp4 = gt;
	cp4.fun();
	return 0;
}

//Teacher->fun()

  • 协变函数的重写，发生了动态联编：

    text
    #include<iostream>
using namespace std;
class Person
{
public:
	virtual Person* fun()//返回父类指针
	{
		cout << "Person->fun()" << endl;
		return nullptr;
	}
};
class Student:public Person
{
public:
	//返回子类指针，虽然返回值不同，也构成重写
	virtual Student* fun()//子类重写父类虚函数
	{
		cout << "Student->fun()" << endl;
		return nullptr;
	}
};
int main()
{
	Person p;
	Student s;
	Person* pp = &p;
	pp->fun();
	pp = &s;
	pp->fun();//执行Student的成员函数
	return 0;
}

  • 虚函数表指针的占用大小和实际作用：

    sizeof 的数值依赖编译器、目标架构和 ABI，也包括对齐填充。下面保留原文的 64 位、32 位数值作为历史记录，原编译器与选项未记录；它们不是所有环境的保证值。填充也不等于每个 int 本身都变成了 8 字节。

    text
    #include<iostream>
using namespace std;
class Base
{
public:
	int i;
	virtual void Print() { } // 虚函数
	virtual void Print2() { } // 虚函数
};

class Derived : public Base
{
public:
	int n;
	virtual void Print() { } // 虚函数
	virtual void Print2() { } // 虚函数
};

class Base2
{
public:
	int i;
	void Print() { }
};

int main()
{
	Base2 b;
	Base bb;
	Derived d;
	//原文记录的某个64位环境结果（编译器与选项未记录）
	cout << sizeof(b) << endl;   //原记录:4
	cout << sizeof(bb) << endl;  //原记录:16，包含对象布局和填充
	cout << sizeof(d) << endl;   //原记录:24，包含对象布局和填充

	cout << sizeof(Base2) << endl;   //原记录:4
	cout << sizeof(Base) << endl;    //原记录:16
	cout << sizeof(Derived) << endl; //原记录:24
	//原文记录的某个32位环境结果（编译器与选项未记录）
	cout << sizeof(b) << endl;   //原记录:4
	cout << sizeof(bb) << endl;  //原记录:8
	cout << sizeof(d) << endl;   //原记录:12

	cout << sizeof(Base2) << endl;   //原记录:4
	cout << sizeof(Base) << endl;    //原记录:8
	cout << sizeof(Derived) << endl; //原记录:12
	
	Base* pb = &d;
	pb->Print(); //调用 Derived::Print()；此函数体为空
	//以下是原文中的错误实验，已禁用：
	//int* p1 = (int*)&bb;
	//int* p2 = (int*)pb;
	//*p2 = *p1; //不允许据此改写所谓 vptr，行为未定义
	//pb->Print(); //不能对错误写入后的调用结果作保证
	return 0;
}

    修改前的 pb->Print() 按虚调用规则选择 Derived::Print()，这里的函数体为空，不会输出 Derive。原文通过 int* 读写对象开头、再断言调用改为 Base::Print() 的做法没有标准保证；这种类型访问会产生未定义行为，改成 double* 也不能解决。因此保留错误实验为注释，不把它作为可执行示例。依据见 C++ 工作草案的类型访问规则。

  • 虚析构函数的实际效果：

    下面的 A 有虚析构函数，A* 指向 B 对象时，delete a 会先执行 B 的析构函数，再执行 A 的析构函数。

    A2 的析构函数非虚，原文的 A2* a2 = new B2; delete a2; 属于未定义行为，不能把结果概括为“只调用基类析构函数”。这段错误操作已注释禁用。

using namespace std;
class A
{
public:
	virtual  ~A()
	{
		cout << "~A()" << endl;
	}
};
class B : public A
{
public:
	virtual ~B()
	{
		cout << "~B()" << endl;
	}
};
class A2
{
public:
	 ~A2()
	{
		cout << "~A2()" << endl;
	}
};
class B2 : public A2
{
public:
	~B2()
	{
		cout << "~B2()" << endl;
	}
};
int main()
{
	A* a = new B;
	delete a;
	//~B()
	//~A()

  • override && final：下面两段故意保留编译错误，用来展示检查规则，不能直接当作通过编译的程序。

    text
    #include<iostream>
using namespace std;
class A
{
public:
	virtual void fun() {}
};

class B : public A
{
public:
	//正确,前面有声明的成员虚函数可供其重写,不会报错
	virtual void fun()  override{}
	//错误:使用“override”声明的成员函数不能重写基类成员
	//也就是前面必须有基类成员声明为了虚函数可供其重写
	virtual void fun2() override{}
};
    text
    #include<iostream>
using namespace std;
class A final //A类无法被继承
{
public:
	virtual void fun() final //fun函数无法被重写
	{}
};

class B : public A //错误:不能将final类类型作为基类
{
public:
	virtual void fun() //错误:不能重写final中的虚函数
	{
		cout << endl;
	}
};
