c++类——复制构造函数(含深浅拷贝)

介绍复制构造函数的调用场景，并用含指针成员的对象说明浅拷贝与深拷贝

（一）引言:

对于普通类型，复制是极其简单的：

text
int a=1;
int b=a;//复制
int *p1=&a;
int *p2=p1;//复制

但对于内部含有多个数据成员的类对象，其结构复杂，复制也相对复杂。

这时就需要调用复制构造函数来完成拷贝过程。

（二）概念:

复制构造函数又名拷贝构造函数，是一种特殊的构造函数，它通过编译器调用完成基于同一类的其他对象的构造及初始化。

复制构造函数必须是非模板构造函数。对类 X，它的第一个形参类型可以是 X&、const X&、volatile X& 或 const volatile X&；其余形参可以存在，但都必须有默认实参。常见写法是 X(const X&)，通过 const 限制对源对象的修改。

  • X(X) 这种按值接收本类对象、且没有其他必填参数的声明不符合语言规则，会在编译时被拒绝。
  • X(X*) 是接收指针的普通构造函数，不属于复制构造函数；是否发生重载歧义，要看具体的其他声明和调用。

对本文这种普通类，如果没有用户声明的复制构造函数，编译器会隐式声明一个。隐式声明不保证它可用：例如，类声明了移动构造函数或移动赋值运算符时，隐式复制构造函数会被定义为删除；成员或基类无法复制，也可能使默认复制构造函数被删除。

（三）调用时机:

  1. 对象以值传递的方式传入函数参数。

    text
    #include <iostream>
using namespace std;
class Time
{
private:
	int hour;  
	int minute;
	int sec;
public:
	Time() { hour = minute = sec = 0; }
	Time(int i1, int i2, int i3) :hour(i1), minute(i2), sec(i3) {}
	Time(const Time& t) 
	{
		hour = t.hour;
		minute = t.minute;
		sec = t.sec;
		cout << "复制构造函数" << endl;
	}//复制构造函数
	void set_time()
	{
		cin >> hour >> minute >> sec;
		return;
	}
	void show_time()
	{
		cout << hour << ":" << minute << ":" << sec << endl;
	}
};
void test(Time t) 
{
	return;
}
int main()
{
	Time t1(4, 5, 6);
	test(t1);//发生复制
	t1.show_time();
	return 0;
}

    调用 test(t1) 时，形参对象 t 由左值对象 t1 复制构造，随后执行函数体。形参在函数退出时或包含该调用的完整表达式结束时销毁，具体时机由实现规定。

  2. 函数按值返回对象时，可能调用复制构造函数。

    text
    #include <iostream>
using namespace std;
class Time
{
private:
	int hour;  
	int minute;
	int sec;
public:
	Time() { hour = minute = sec = 0; }
	Time(int i1, int i2, int i3) :hour(i1), minute(i2), sec(i3) {}
	Time(const Time& t) 
	{
		hour = t.hour;
		minute = t.minute;
		sec = t.sec;
		cout << "复制构造函数" << endl;
	}//复制构造函数
	void set_time()
	{
		cin >> hour >> minute >> sec;
		return;
	}
	void show_time()
	{
		cout << hour << ":" << minute << ":" << sec << endl;
	}
};
Time test(int i1,int i2,int i3) 
{
	Time t(i1, i2, i3);
	return t;//这里允许省略复制；未省略时，本例调用复制构造函数
}
int main()
{
	Time t1(4, 5, 6);
	t1 = test(10, 9, 8);
	t1.show_time();
	return 0;
}

    这里的 return t 满足命名返回值优化（NRVO）的条件，编译器可以直接在返回结果的位置构造 t，省略这次复制；未省略时，本例会调用复制构造函数。t1 = test(10, 9, 8) 中的 t1 已经存在，因此接收结果的步骤调用赋值运算符。具体构造、析构次数取决于是否进行了复制省略。

  3. 对象需要通过另外一个对象进行初始化。

  4. 复制含类类型成员的对象。

    text
    #include <iostream>
using namespace std;
class year
{
private:
	int years;
public:
	year() { years = 0; }
	year(const year& y) { cout << "year复制构造函数" << endl; }//year的复制构造函数
};
class Time
{
private:
	int hour;  
	int minute;
	int sec;
	year y;
public:
	Time() { hour = minute = sec = 0; }
	Time(int i1, int i2, int i3) :hour(i1), minute(i2), sec(i3) {}
	void set_time()
	{
		cin >> hour >> minute >> sec;
		return;
	}
	void show_time()
	{
		cout << hour << ":" << minute << ":" << sec << endl;
	}
};
int main()
{
	Time t1(4, 5, 6);
	Time t2 = t1;//由 Time 的隐式复制构造函数调用 year 的复制构造函数。
	t1.show_time();
	return 0;
}

    这里没有为 Time 显式声明复制构造函数，编译器会隐式声明并按需定义它，逐个初始化基类和非静态数据成员。复制 y 时会调用 year 的复制构造函数。

    如果为 Time 自己编写复制构造函数，可以在成员初始化列表中写 y(t.y)，使 y 由源对象的对应成员复制构造。这两段示例中的 year 复制构造函数只打印提示，尚未初始化 years，用于观察调用关系。

    代码如下：

    text
    #include <iostream>
using namespace std;
class year
{
private:
	int years;
public:
	year() { years = 0; }
	year(const year& y) {cout << "year复制构造函数" << endl;}//year复制构造函数
};
class Time
{
private:
	int hour;  
	int minute;
	int sec;
	year y;
public:
	Time() { hour = minute = sec = 0; }
	Time(int i1, int i2, int i3) :hour(i1), minute(i2), sec(i3) {}
	Time(const Time& t):y(t.y)
	{
		hour = t.hour;
		minute = t.minute;
		sec = t.sec;
		cout << "复制构造函数" << endl;
	}//复制构造函数
	void set_time()
	{
		cin >> hour >> minute >> sec;
		return;
	}
	void show_time()
	{
		cout << hour << ":" << minute << ":" << sec << endl;
	}
};
int main()
{
	Time t1(4, 5, 6);
	Time t2 = t1;//发生复制，且调用了各自的复制构造函数
	t1.show_time();
	return 0;
}

（四）浅拷贝和深拷贝:

  1. 默认拷贝构造函数：

    编译器隐式声明的复制构造函数可能被定义为删除；能否使用取决于类及其成员、基类的定义。

    可用的默认复制构造函数会逐个复制初始化基类和非静态数据成员。类类型成员调用相应的复制构造函数，原始指针成员复制指针值。静态数据成员不属于每个对象的子对象，无需在复制对象时另行复制。

  2. 浅拷贝：

    本文用含原始指针的类说明浅拷贝：复制对象时直接复制指针值，两个对象的指针便指向同一资源。修改其中一个指针变量本身，不会改变另一个指针；通过它修改共享资源时，另一个对象也会观察到资源的变化。

    下面是说明重复释放的错误示例，请勿直接运行。下面的类在析构函数中释放 p 所指的对象；默认复制后，两个对象都会尝试释放同一资源：

    text
    #include <iostream>
using namespace std;
class Time
{
private:
	int hour;  
	int minute;
	int sec;
	int* p;
public:
	Time() { hour = minute = sec = 0; p = new int(10); }
	Time(int i1, int i2, int i3) :hour(i1), minute(i2), sec(i3) { p = new int(5); }
	~Time() 
	{
		delete p;
	}
	void set_time()
	{
		cin >> hour >> minute >> sec;
		return;
	}
	void show_time()
	{
		cout << hour << ":" << minute << ":" << sec << endl;
	}
};
int main()
{
	Time t1(4, 5, 6);
	Time t2(t1);
	t2.show_time();
	return 0;
}

    按代码推演，t1 和 t2 是两个独立的对象，但默认复制使两个成员 p 保存相同的指针值，指向同一个动态分配的 int。

    其中一个对象析构并释放资源后，另一个对象的 p 成为悬空指针；随后再次 delete 会导致未定义行为。这个例子分配的是单个 int。

    如果希望两个对象各自拥有内容相同、互不影响的资源，就需要为复制后的对象另行分配空间。

  3. 深拷贝：

    在这个例子中，深拷贝需要为新对象的 p 另行分配一个 int，再复制原来 p 所指的值。这样两个 Time 对象分别拥有自己的资源。

    对象本身可以具有自动存储期，例如下方 main 中的 t1、t2；需要另行分配的是它们管理的资源。

    代码如下：

    text
    #include <iostream>
using namespace std;
class Time
{
private:
	int hour;  
	int minute;
	int sec;
	int* p;
public:
	Time() { hour = minute = sec = 0; p = new int(10); }
	Time(int i1, int i2, int i3) :hour(i1), minute(i2), sec(i3) { p = new int(10); }
	Time(const Time& t)
	{
		hour = t.hour;
		minute = t.minute;
		sec = t.sec;
		p=new int(*t.p);
		cout << "复制构造函数" << endl;
	}//复制构造函数
	~Time() 
	{
		if (p != NULL) {
			cout << "析构"<<&p << endl;
			delete p;
			p = NULL;
		}
	}
	void set_time()
	{
		cin >> hour >> minute >> sec;
		return;
	}
	void show_time()
	{
		cout << hour << ":" << minute << ":" << sec << endl;
	}
};
int main()
{
	Time t1(4, 5, 6);
	Time t2(t1);//发生复制
	t2.show_time();
	return 0;
}

    从 p = new int(*t.p) 可以看出，这个复制构造函数为 t2.p 分配了独立的 int，并复制 t1.p 所指的值。析构函数打印的是 &p，即指针成员自身的地址；要观察它保存的地址，应输出 p。本例展示的是复制构造，尚未定义管理该资源的复制赋值运算符。

  4. 防止浅拷贝发生：

    将复制构造函数声明为私有且不提供定义，会使外部需要调用它的复制构造无法通过访问检查；成员和友元仍可能引用它。也可以写 X(const X&) = delete;，明确禁止相应的复制构造。若还要禁止对已有对象的复制赋值，需要同时处理复制赋值运算符。
