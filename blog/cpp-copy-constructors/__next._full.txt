1d:T365b,<span id="一引言" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-一引言">（一）引言:</h3>
<p>对于普通类型，复制是极其简单的：</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>int a=1;
int b=a;//复制
int *p1=&#x26;a;
int *p2=p1;//复制
</code></pre></div>
<p>但对于内部含有多个数据成员的类对象，其结构复杂，复制也相对复杂。</p>
<p>这时就需要调用复制构造函数来完成拷贝过程。</p>
<span id="二概念" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-二概念">（二）概念:</h3>
<p>复制构造函数又名拷贝构造函数，是一种特殊的构造函数，它通过编译器调用完成基于同一类的其他对象的构造及初始化。</p>
<p>复制构造函数必须是非模板构造函数。对类 <code>X</code>，它的第一个形参类型可以是 <code>X&#x26;</code>、<code>const X&#x26;</code>、<code>volatile X&#x26;</code> 或 <code>const volatile X&#x26;</code>；其余形参可以存在，但都必须有默认实参。常见写法是 <code>X(const X&#x26;)</code>，通过 <code>const</code> 限制对源对象的修改。</p>
<ul>
<li><code>X(X)</code> 这种按值接收本类对象、且没有其他必填参数的声明不符合语言规则，会在编译时被拒绝。</li>
<li><code>X(X*)</code> 是接收指针的普通构造函数，不属于复制构造函数；是否发生重载歧义，要看具体的其他声明和调用。</li>
</ul>
<p>对本文这种普通类，如果没有用户声明的复制构造函数，编译器会隐式声明一个。隐式声明不保证它可用：例如，类声明了移动构造函数或移动赋值运算符时，隐式复制构造函数会被定义为删除；成员或基类无法复制，也可能使默认复制构造函数被删除。</p>
<span id="三调用时机" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-三调用时机">（三）调用时机:</h3>
<ol>
<li>

</li>

<span id="四浅拷贝和深拷贝" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-四浅拷贝和深拷贝">（四）浅拷贝和深拷贝:</h3>
<ol>
<li>
<p><strong>默认拷贝构造函数</strong>：</p>
<p>编译器隐式声明的复制构造函数可能被定义为删除；能否使用取决于类及其成员、基类的定义。</p>
<p>可用的默认复制构造函数会逐个复制初始化基类和非静态数据成员。类类型成员调用相应的复制构造函数，原始指针成员复制指针值。静态数据成员不属于每个对象的子对象，无需在复制对象时另行复制。</p>
</li>
<li>
<p><strong>浅拷贝</strong>：</p>
<p>本文用含原始指针的类说明浅拷贝：复制对象时直接复制指针值，两个对象的指针便指向同一资源。修改其中一个指针变量本身，不会改变另一个指针；通过它修改共享资源时，另一个对象也会观察到资源的变化。</p>
<p>下面是说明重复释放的错误示例，请勿直接运行。下面的类在析构函数中释放 <code>p</code> 所指的对象；默认复制后，两个对象都会尝试释放同一资源：</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>#include &#x3C;iostream>
using namespace std;
class Time
{
private:
	int hour;  
	int minute;
	int sec;
	int* p;
public:
	Time() { hour = minute = sec = 0; p = new int(10); }
	Time(int i1, int i2, int i3) :hour(i1), minute(i2), sec(i3) { p = new int(5); }
	~Time() 
	{
		delete p;
	}
	void set_time()
	{
		cin >> hour >> minute >> sec;
		return;
	}
	void show_time()
	{
		cout &#x3C;&#x3C; hour &#x3C;&#x3C; ":" &#x3C;&#x3C; minute &#x3C;&#x3C; ":" &#x3C;&#x3C; sec &#x3C;&#x3C; endl;
	}
};
int main()
{
	Time t1(4, 5, 6);
	Time t2(t1);
	t2.show_time();
	return 0;
}
</code></pre></div>
<p>按代码推演，<code>t1</code> 和 <code>t2</code> 是两个独立的对象，但默认复制使两个成员 <code>p</code> 保存相同的指针值，指向同一个动态分配的 <code>int</code>。</p>
<p>其中一个对象析构并释放资源后，另一个对象的 <code>p</code> 成为悬空指针；随后再次 <code>delete</code> 会导致未定义行为。这个例子分配的是单个 <code>int</code>。</p>
<p>如果希望两个对象各自拥有内容相同、互不影响的资源，就需要为复制后的对象另行分配空间。</p>
</li>
<li>
<p><strong>深拷贝</strong>：</p>
<p>在这个例子中，深拷贝需要为新对象的 <code>p</code> 另行分配一个 <code>int</code>，再复制原来 <code>p</code> 所指的值。这样两个 <code>Time</code> 对象分别拥有自己的资源。</p>
<p>对象本身可以具有自动存储期，例如下方 <code>main</code> 中的 <code>t1</code>、<code>t2</code>；需要另行分配的是它们管理的资源。</p>
<p>代码如下：</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>#include &#x3C;iostream>
using namespace std;
class Time
{
private:
	int hour;  
	int minute;
	int sec;
	int* p;
public:
	Time() { hour = minute = sec = 0; p = new int(10); }
	Time(int i1, int i2, int i3) :hour(i1), minute(i2), sec(i3) { p = new int(10); }
	Time(const Time&#x26; t)
	{
		hour = t.hour;
		minute = t.minute;
		sec = t.sec;
		p=new int(*t.p);
		cout &#x3C;&#x3C; "复制构造函数" &#x3C;&#x3C; endl;
	}//复制构造函数
	~Time() 
	{
		if (p != NULL) {
			cout &#x3C;&#x3C; "析构"&#x3C;&#x3C;&#x26;p &#x3C;&#x3C; endl;
			delete p;
			p = NULL;
		}
	}
	void set_time()
	{
		cin >> hour >> minute >> sec;
		return;
	}
	void show_time()
	{
		cout &#x3C;&#x3C; hour &#x3C;&#x3C; ":" &#x3C;&#x3C; minute &#x3C;&#x3C; ":" &#x3C;&#x3C; sec &#x3C;&#x3C; endl;
	}
};
int main()
{
	Time t1(4, 5, 6);
	Time t2(t1);//发生复制
	t2.show_time();
	return 0;
}
</code></pre></div>
<p>从 <code>p = new int(*t.p)</code> 可以看出，这个复制构造函数为 <code>t2.p</code> 分配了独立的 <code>int</code>，并复制 <code>t1.p</code> 所指的值。析构函数打印的是 <code>&#x26;p</code>，即指针成员自身的地址；要观察它保存的地址，应输出 <code>p</code>。本例展示的是复制构造，尚未定义管理该资源的复制赋值运算符。</p>
</li>
<li>
<p><strong>防止浅拷贝发生</strong>：</p>
<p>将复制构造函数声明为私有且不提供定义，会使外部需要调用它的复制构造无法通过访问检查；成员和友元仍可能引用它。也可以写 <code>X(const X&#x26;) = delete;</code>，明确禁止相应的复制构造。若还要禁止对已有对象的复制赋值，需要同时处理复制赋值运算符。</p>
</li>
</ol>
