29:T2eec,<h2 id="section-区域和检索用累计结果消除重复求和">区域和检索：用累计结果消除重复求和</h2>
<section class="problem"><div class="problem-heading"><strong>303. 区域和检索—数组不可变</strong><a href="https://leetcode.cn/problems/range-sum-query-immutable/" rel="noopener noreferrer">完整力扣题面 ↗</a></div><p class="excerpt-label">题面原文节选</p><blockquote>给定一个整数数组 nums，处理以下类型的多个查询:</blockquote><div class="examples"><b>示例输入与输出</b><code>nums=[-2,0,3,-5,2,-1]；sumRange(0,2) → 1，sumRange(2,5) → -1，sumRange(0,5) → -3</code></div><p><b>任务与约束：</b>实现NumArray(nums)与sumRange(left,right)，查询含两端的区间和。n为1～10⁴，元素为−10⁵～10⁵，最多10⁴次查询，0≤left≤right&#x3C;n。</p></section>
<p>数组不变，却需要多次查询不同区间的和。如果每次都重新遍历区间，重叠部分就会被反复累加。<strong>前缀和保存从数组开头累加到各个位置的结果，让区间求和变成两个累计值相减。</strong></p>
<h3 id="section-前缀下标表示已累计的元素数量">前缀下标表示已累计的元素数量</h3>
<p>令<code>P[0]=0</code>，<code>P[i]</code>表示原数组前i个元素之和。原数组长n，前缀表就有n＋1项：</p>
<p><span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>P</mi><mo stretchy="false">[</mo><mi>i</mi><mo>+</mo><mn>1</mn><mo stretchy="false">]</mo><mo>=</mo><mi>P</mi><mo stretchy="false">[</mo><mi>i</mi><mo stretchy="false">]</mo><mo>+</mo><mi>n</mi><mi>u</mi><mi>m</mi><mi>s</mi><mo stretchy="false">[</mo><mi>i</mi><mo stretchy="false">]</mo></mrow><annotation encoding="application/x-tex">P[i+1]=P[i]+nums[i]</annotation></semantics></math></span></p>
<p>对于从0开始的闭区间<code>[l,r]</code>，<code>P[r+1]</code>包含下标0到r，减去包含0到l−1的<code>P[l]</code>，恰好留下所需部分：</p>
<p><span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi mathvariant="normal">sum</mi><mo>⁡</mo><mo stretchy="false">(</mo><mi>n</mi><mi>u</mi><mi>m</mi><mi>s</mi><mo stretchy="false">[</mo><mi>l</mi><mo>:</mo><mi>r</mi><mo>+</mo><mn>1</mn><mo stretchy="false">]</mo><mo stretchy="false">)</mo><mo>=</mo><mi>P</mi><mo stretchy="false">[</mo><mi>r</mi><mo>+</mo><mn>1</mn><mo stretchy="false">]</mo><mo>−</mo><mi>P</mi><mo stretchy="false">[</mo><mi>l</mi><mo stretchy="false">]</mo></mrow><annotation encoding="application/x-tex">\operatorname{sum}(nums[l:r+1])=P[r+1]-P[l]</annotation></semantics></math></span></p>
<p><strong>P的下标是前缀长度，并不等于正在加入的元素下标。</strong>空前缀0使从数组开头出发的区间也能用同一条公式，无需给l＝0另写分支。</p>
<figure class="explain-figure"><figcaption>前缀长度与原数组下标要分别看</figcaption><div class="lane"><b>nums下标0、1、2</b><div class="cells"><div class="cell"><small>下标0</small><b>2</b></div><div class="cell active"><small>下标1</small><b>-1</b></div><div class="cell active"><small>下标2</small><b>3</b></div></div></div><div class="prefix-grid"><div class=""><small>P[0] · 前0项</small><b>0</b></div><div class="selected"><small>P[1] · 前1项</small><b>2</b></div><div class=""><small>P[2] · 前2项</small><b>1</b></div><div class="selected"><small>P[3] · 前3项</small><b>4</b></div></div><p>绿色选中的原数组区间为[1,2]。蓝框选出两个累计量：<b>P[3]−P[1]＝4−2＝2</b>，去掉了前1项。</p></figure>
<p>例如<code>nums=[2,-1,3]</code>，前缀表为<code>[0,2,1,4]</code>。原数组区间<code>[1,2]</code>的和是<code>P[3]-P[1]=4-2=2</code>。前缀和允许负数，前缀表也可能下降；构造和相减都不要求表有序。</p>
<h3 id="section-在numarray中预处理一次之后直接查询">在NumArray中预处理一次，之后直接查询</h3>
<div class="code-block"><div class="code-toolbar"><span>python</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code class="hljs language-python"><span class="hljs-keyword">class</span> <span class="hljs-title class_">NumArray</span>:

    <span class="hljs-keyword">def</span> <span class="hljs-title function_">__init__</span>(<span class="hljs-params">self, nums: <span class="hljs-built_in">list</span>[<span class="hljs-built_in">int</span>]</span>):
        <span class="hljs-variable language_">self</span>.prefix = [<span class="hljs-number">0</span>]  <span class="hljs-comment"># prefix[i]表示前i个数之和，prefix[0]是空前缀。</span>
        <span class="hljs-keyword">for</span> value <span class="hljs-keyword">in</span> nums:
            <span class="hljs-variable language_">self</span>.prefix.append(<span class="hljs-variable language_">self</span>.prefix[-<span class="hljs-number">1</span>] + value)

    <span class="hljs-keyword">def</span> <span class="hljs-title function_">sumRange</span>(<span class="hljs-params">self, left: <span class="hljs-built_in">int</span>, right: <span class="hljs-built_in">int</span></span>) -> <span class="hljs-built_in">int</span>:
        <span class="hljs-comment"># 题目是闭区间[left,right]，对应前缀下标right+1与left。</span>
        <span class="hljs-keyword">return</span> <span class="hljs-variable language_">self</span>.prefix[right + <span class="hljs-number">1</span>] - <span class="hljs-variable language_">self</span>.prefix[left]
</code></pre></div>
<p>初始化需要扫描n项，花O(n)时间、O(n)额外空间。每次<code>sumRange</code>只读取两项并相减，是O(1)时间；q次查询加上初始化，总时间为<strong>O(n+q)</strong>。</p>
<p>直接使用<code>sum(nums[left:right+1])</code>时，每次都要重新扫描，还会创建切片，最坏总时间为O(nq)。前缀表省去的就是这部分重复加法与切片，不会把初始化本身也变成O(1)。</p>
<p>单点区间返回该元素，整段查询返回最后的前缀值。题目保证<code>0&#x3C;=left&#x3C;=right&#x3C;n</code>；这份代码没有另外提供非法下标检查。<strong>数组不可变也是前提</strong>：原数组改变后，这张静态表不会自动更新。</p>
<h2 id="section-560和为k的子数组把区间关系改写成旧前缀查询">560和为K的子数组：把区间关系改写成旧前缀查询</h2>
<section class="problem"><div class="problem-heading"><strong>560. 和为K的子数组</strong><a href="https://leetcode.cn/problems/subarray-sum-equals-k/" rel="noopener noreferrer">完整力扣题面 ↗</a></div><p class="excerpt-label">题面原文节选</p><blockquote>给你一个整数数组 nums 和一个整数 k ，请你统计并返回 该数组中和为 k 的子数组的个数 。</blockquote><div class="examples"><b>示例输入与输出</b><code>nums=[1,1,1], k=2 → 2；nums=[1,2,3], k=3 → 2</code></div><p><b>任务与约束：</b>子数组为连续非空序列。n为1～2×10⁴，元素为−1000～1000，k为−10⁷～10⁷。</p></section>
<p>303已经给定区间两端，560需要找出所有满足条件的区间。即使每个区间的和都能O(1)计算，n个元素仍然有<code>n(n+1)/2</code>个非空连续区间，逐一枚举的时间还是O(n²)。</p>
<details class="extra">
<summary>展开前缀和＋枚举两端的推导版本</summary>
<div class="code-block"><div class="code-toolbar"><span>python</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code class="hljs language-python"><span class="hljs-keyword">def</span> <span class="hljs-title function_">subarray_sum_quadratic</span>(<span class="hljs-params">nums: <span class="hljs-built_in">list</span>[<span class="hljs-built_in">int</span>], k: <span class="hljs-built_in">int</span></span>) -> <span class="hljs-built_in">int</span>:
    prefix = [<span class="hljs-number">0</span>]
    <span class="hljs-keyword">for</span> value <span class="hljs-keyword">in</span> nums:
        prefix.append(prefix[-<span class="hljs-number">1</span>] + value)
    answer = <span class="hljs-number">0</span>
    <span class="hljs-keyword">for</span> end <span class="hljs-keyword">in</span> <span class="hljs-built_in">range</span>(<span class="hljs-number">1</span>, <span class="hljs-built_in">len</span>(prefix)):
        <span class="hljs-keyword">for</span> start <span class="hljs-keyword">in</span> <span class="hljs-built_in">range</span>(end):
            <span class="hljs-keyword">if</span> prefix[end] - prefix[start] == k:
                answer += <span class="hljs-number">1</span>
    <span class="hljs-keyword">return</span> answer
</code></pre></div>
</details>
<p>进一步固定当前右边界。用半开区间<code>[start,end)</code>表示子数组，所需条件可以改写成：</p>
<p><span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>P</mi><mo stretchy="false">[</mo><mi>e</mi><mi>n</mi><mi>d</mi><mo stretchy="false">]</mo><mo>−</mo><mi>P</mi><mo stretchy="false">[</mo><mi>s</mi><mi>t</mi><mi>a</mi><mi>r</mi><mi>t</mi><mo stretchy="false">]</mo><mo>=</mo><mi>k</mi><mspace width="1em"></mspace><mo>⟹</mo><mspace width="1em"></mspace><mi>P</mi><mo stretchy="false">[</mo><mi>s</mi><mi>t</mi><mi>a</mi><mi>r</mi><mi>t</mi><mo stretchy="false">]</mo><mo>=</mo><mi>P</mi><mo stretchy="false">[</mo><mi>e</mi><mi>n</mi><mi>d</mi><mo stretchy="false">]</mo><mo>−</mo><mi>k</mi></mrow><annotation encoding="application/x-tex">P[end]-P[start]=k\quad\Longrightarrow\quad P[start]=P[end]-k</annotation></semantics></math></span></p>
<p><strong>当前前缀P[end]已知后，需要的旧前缀值就确定了，剩下的是查它以前出现过多少次。</strong>因此可以用哈希表保存<code>旧前缀和→出现次数</code>，不再逐个枚举起点。</p>
<h3 id="section-旧前缀频次对应所有合法起点">旧前缀频次对应所有合法起点</h3>
<p>不同起点可能有相同的前缀和。例如<code>[1,-1,1]</code>中，空前缀为0，读完前两个元素后的前缀也为0。它们分别对应起点0和起点2，都能与最后的前缀1组成和为1的子数组。</p>
<p>集合只能回答有没有这个旧前缀，最后一个下标只能保留一个起点；<strong>统计所有合法区间时，需要把相同前缀对应的起点数量全部加进答案</strong>。</p>

<h3 id="section-空前缀初始化与先查询再记录的顺序">空前缀初始化与先查询再记录的顺序</h3>
<p>初始<code>frequency={0:1}</code>表示<strong>数组还没读入任何元素时，累计和0已经出现一次</strong>。这样，从下标0开始、恰好和为k的区间也能被查询到。这里不是预先记录了一个答案，而是记录一个可用起点。</p>
<p>每轮先查询<code>running-k</code>，再把当前running加入表中。这个顺序保证查到的前缀都来自以前，即<strong>start&#x3C;end，区间至少包含一个元素</strong>。如果先记当前前缀，在k＝0时就会把当前前缀与自身配对，错误计入空区间。</p>
<p>以<code>[0,0,0]、k=0</code>为例，三个右端分别能得到1、2、3个有效起点，总数为6。频次表中的0依次从1增加到4，但每一步查询使用的是增加前的次数。</p>
<p><strong>循环不变量是：查询当前前缀时，表中恰好记录所有更早前缀的出现次数，答案已包含此前各右端对应的合法区间。</strong>当前右端新增的区间数由一次频次查询给出，随后记录当前前缀，供下一轮使用。每个区间只会在它自己的右端被统计一次。</p>
<h3 id="section-560的时间空间与适用边界">560的时间、空间与适用边界</h3>
<p>每个元素只进行一次累计、一次哈希查询和一次频次更新。在哈希操作平均O(1)的前提下，<strong>总时间为平均O(n)，辅助空间最坏为O(n)</strong>。如果所有前缀都不同，表中最多保存n＋1个键；许多前缀重复时，键数会更少，但不能因此把一般空间复杂度写成O(1)。</p>
<p>这里无需另外保存完整的前缀数组，只维护当前累计和及旧频次。与前缀枚举法相比，省掉的是枚举旧起点的工作。用大整数时还需考虑整数运算成本，本文按题目范围采用常见的单位操作复杂度口径。</p>
<p>负数和0都可以正常处理，因为<strong>等值哈希查询不依赖前缀的单调性</strong>。没有满足条件的区间返回0；k为负也不影响关系式。原题输入非空，代码额外兼容空列表并返回0。</p>
