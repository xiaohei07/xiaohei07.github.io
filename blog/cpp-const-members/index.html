（一）概念:

类的常成员包括常数据成员，常成员函数，常对象。

下面每一部分分别介绍一个内容。文中的代码故意保留了标为“错误”的语句，用来展示限制；这些代码块不能直接作为完整的可编译示例。

（二）常数据成员：

1. 概念：

常数据成员使用 const 限定。本文的 const int 成员在初始化后不能再修改，初始化与后续赋值需要分开理解。

形式为：const 类型 数据成员名;

2. 特点：

  • 不同对象的相同常数据成员可以不同，但对于单个对象来说，常数据成员在初始化后是不可变的。

  • 常数据成员要在执行构造函数体之前完成初始化。可以使用构造函数的成员初始化列表；从 C++11 起，也可以在类内给出默认成员初始化器，例如 const int x = 0;。如果构造函数又在初始化列表中指定 x，会使用该初始化列表中的值。构造函数体内的 x = ... 已经是赋值，不能用于修改这个常成员。

  • 对于任何函数，无论是成员函数、友元函数还是类外函数，均不允许修改其值，只能读取。

3. 代码实现：

text
#include <iostream>
using namespace std;
class Simple
{
private:
	const int x;
	int y;
public:
	Simple():x(0)
	{
		x=0;//错误！不允许在构造函数体内初始化常数据成员x的值！
		cout << "创建对象" << endl;
		y = 0; 
	};
	Simple (int a, int b) : x(a), y(b)
	{
		cout << "创建对象" << endl;
	}
	void showXY() 
	{
		cout << x << "," << y << endl;
	}
	void resetXY(int a, int b) 
	{
		x = a, y = b; //错误！不允许修改常数据成员x的值！
		return ;
	}
	void Simple_thisuse(int a,int b)
	{
		cout << this->x << " " << this->y << endl;
		(*this).x += a;//错误！不允许修改常数据成员x的值！
		(*this).y += b;
		cout << this->x << " " << this->y << endl;
		cout << this << endl;
		return;
	}
	~Simple()
	{
		cout << "释放对象" << endl;
	}
};
int main()
{
	Simple ss;
	Simple s(1, 2);//在构造函数处对常数据成员赋值
	ss.showXY();
	return 0;
}

（三）常成员函数：

1. 概念：

在普通非静态成员函数的参数列表后加上 const，就把它声明为常成员函数。在类 Simple 的这种成员函数中，this 的类型是 const Simple*，即指向常对象的指针；这决定了通过当前对象访问成员时的限制。

形式：返回类型 成员函数名(参数表) const { 成员函数体 }。

写在返回类型位置的 const 修饰的是返回类型，不会把函数变成常成员函数。例如下面代码中的 const void Simple_thisuse(...) 没有达到修饰当前对象的目的，const 应放在参数列表后。

2. 特点：

  • 通过当前对象不能修改普通非静态数据成员；mutable 成员是例外。指针成员指向的其他对象也不自动随当前对象变成只读。
  • 通过当前对象只能调用其他 const 非静态成员函数；这不妨碍调用静态成员函数，或操作另外一个允许修改的对象。
  • 可以被其他不是常成员函数的成员函数调用。
  • 参数列表后的 const 可以用于区分成员函数重载。需要同时支持常对象和非常对象时，可以按需提供两个版本；只读操作通常可以直接提供 const 版本。
  • 在类外写实现时const仍要保留。

3. 代码实现：

text
#include <iostream>
using namespace std;
class Simple
{
private:
	int x;
	int y;
public:
	Simple():x(0),y(0)
	{
		cout << "创建对象" << endl;

	};
	Simple (int a, int b) : x(a), y(b)
	{
		cout << "创建对象" << endl;
	}
	void showXY()
	{
		cout << x << "," << y << endl;
	}
	void showXY() const  //正确，不修改任意成员变量，可以加const
	{
		cout << x << "," << y << endl;
	}
	void resetXY(int a, int b) 
	{
		x = a, y = b;
		return ;
	}
	void resetXY(int a, int b) const //错误，修改了成员变量，不可以加const
	{
		x = a, y = b; 
		return;
	}
	const void Simple_thisuse(int a,int b) //const加入位置错误
	{
		cout << this->x << " " << this->y << endl;
		(*this).x += a;
		(*this).y += b;
		cout << this->x << " " << this->y << endl;
		cout << this << endl;
		return;
	}
	~Simple()
	{
		cout << "释放对象" << endl;
	}
};
int main()
{

	Simple ss;
	Simple s(1, 2);
	ss.showXY();
	return 0;
}

（四）常对象：

1. 概念：

在声明对象前加const称该对象为常对象。

形式：类名 const 对象名[(参数表)] / const 类名 对象名[(参数表)] 两种意义相同。

2. 特点：

  • 通过常对象调用普通非静态成员函数时，只能选用 const 版本；它的普通非静态数据成员不能通过该对象修改，mutable 成员除外。

  • 构造时应把需要读取的数据成员初始化好；const 本身不会替所有成员自动填写初值。

  • 类里仍可同时定义 const 和非 const 成员函数。把对象声明为 const，不会把非 const 成员函数自动变成 const 版本。

3.代码实现：

text
#include <iostream>
using namespace std;
class Simple
{
private:
	int x;
	int y;
public:
	Simple():x(0),y(0)
	{
		cout << "创建对象" << endl;

	};
	Simple (int a, int b) : x(a), y(b)
	{
		cout << "创建对象" << endl;
	}
	void showXY()
	{
		cout << x << "," << y << endl;
	}
	void showXY() const  //正确，不修改任意成员变量，可以加const
	{
		cout << "调用const版本:" << endl;
		cout << x << "," << y << endl;
	}
	void resetXY(int a, int b) 
	{
		x = a, y = b;
		return ;
	}

	const void Simple_thisuse(int a,int b) //const加入位置错误
	{
		cout << this->x << " " << this->y << endl;
		(*this).x += a;
		(*this).y += b;
		cout << this->x << " " << this->y << endl;
		cout << this << endl;
		return;
	}
	~Simple()
	{
		cout << "释放对象" << endl;
	}
};
int main()
{
	Simple ss;
	Simple s(1, 2);
	ss.showXY();
	const Simple s1;
	Simple const s2(2, 3);//两种都可以
	s1.resetXY(1, 2);//不可以调用非常成员函数
	s2.showXY();//调用const版本
	return 0;
}
