12:T249d,<span id="一概念" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-一概念">（一）概念:</h3>
<p>类的常成员包括常数据成员，常成员函数，常对象。</p>
<p>下面每一部分分别介绍一个内容。文中的代码故意保留了标为“错误”的语句，用来展示限制；这些代码块不能直接作为完整的可编译示例。</p>
<span id="二常数据成员" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-二常数据成员">（二）常数据成员：</h3>
<span id="1-概念" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-1-概念">1. 概念：</h4>
<p>常数据成员使用 <code>const</code> 限定。本文的 <code>const int</code> 成员在初始化后不能再修改，初始化与后续赋值需要分开理解。</p>
<p>形式为：<em><strong>const 类型 数据成员名;</strong></em></p>
<span id="2-特点" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-2-特点">2. 特点：</h4>
<ul>
<li>
<p>不同对象的相同常数据成员可以不同，但对于单个对象来说，常数据成员在初始化后是不可变的。</p>
</li>
<li>
<p>常数据成员要在执行构造函数体之前完成初始化。可以使用构造函数的成员初始化列表；从 C++11 起，也可以在类内给出默认成员初始化器，例如 <code>const int x = 0;</code>。如果构造函数又在初始化列表中指定 <code>x</code>，会使用该初始化列表中的值。构造函数体内的 <code>x = ...</code> 已经是赋值，不能用于修改这个常成员。</p>
</li>
<li>
<p>对于任何函数，无论是成员函数、友元函数还是类外函数，均不允许修改其值，只能读取。</p>
</li>
</ul>

<span id="三常成员函数" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-三常成员函数">（三）常成员函数：</h3>
<h4 id="section-1-概念-1">1. 概念：</h4>
<p>在普通非静态成员函数的参数列表后加上 <code>const</code>，就把它声明为常成员函数。在类 <code>Simple</code> 的这种成员函数中，<code>this</code> 的类型是 <code>const Simple*</code>，即指向常对象的指针；这决定了通过当前对象访问成员时的限制。</p>
<p>形式：<code>返回类型 成员函数名(参数表) const { 成员函数体 }</code>。</p>
<p>写在返回类型位置的 <code>const</code> 修饰的是返回类型，不会把函数变成常成员函数。例如下面代码中的 <code>const void Simple_thisuse(...)</code> 没有达到修饰当前对象的目的，<code>const</code> 应放在参数列表后。</p>
<h4 id="section-2-特点-1">2. 特点：</h4>
<ul>
<li>通过当前对象不能修改普通非静态数据成员；<code>mutable</code> 成员是例外。指针成员指向的其他对象也不自动随当前对象变成只读。</li>
<li>通过当前对象只能调用其他 const 非静态成员函数；这不妨碍调用静态成员函数，或操作另外一个允许修改的对象。</li>
<li>可以被其他不是常成员函数的成员函数调用。</li>
<li>参数列表后的 <code>const</code> 可以用于区分成员函数重载。需要同时支持常对象和非常对象时，可以按需提供两个版本；只读操作通常可以直接提供 const 版本。</li>
<li>在类外写实现时<strong>const仍要保留</strong>。</li>
</ul>

<span id="四常对象" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-四常对象">（四）常对象：</h3>
<h4 id="section-1-概念-2">1. 概念：</h4>
<p>在声明对象前加const称该对象为常对象。</p>
<p>形式：<em><strong>类名 const 对象名[(参数表)]</strong></em> / <em><strong>const 类名 对象名[(参数表)]</strong></em> 两种意义相同。</p>
<h4 id="section-2-特点-2">2. 特点：</h4>
<ul>
<li>
<p>通过常对象调用普通非静态成员函数时，只能选用 const 版本；它的普通非静态数据成员不能通过该对象修改，<code>mutable</code> 成员除外。</p>
</li>
<li>
<p>构造时应把需要读取的数据成员初始化好；<code>const</code> 本身不会替所有成员自动填写初值。</p>
</li>
<li>
<p>类里仍可同时定义 const 和非 const 成员函数。把对象声明为 const，不会把非 const 成员函数自动变成 const 版本。</p>
</li>
</ul>
