1d:T1836,<span id="本文章只介绍理论下一篇讲解实例" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-本文章只介绍理论下一篇讲解实例">本文章只介绍理论，下一篇讲解实例！！</h3>
<span id="一概念" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-一概念">（一）概念：</h3>
<p>分治法，即"分而治之"，意即将一个复杂的问题分解成若干个相同或者相似的子问题，再将这些子问题继续进行分解，直到产生足够简单能够直接求解的子问题。而对原问题的求解，就是对这些子问题的合并。</p>
<p>分治算法可以由递归过程来表示，因为分治法是大规模问题化为小规模问题的方法，是递归设计的一种具体策略。</p>
<p>把问题拆小以后，还需要计算拆分、递归求解和合并的总开销，才能判断这种做法是否节省时间。后面的复杂度分析会把这些开销写成递推式。</p>
<p>分治算法是很多高效算法的基础，如二分查找，归并和快速排序，大整数乘法，矩阵乘法，傅里叶变换等等。</p>
<span id="二基本思想和特征" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-二基本思想和特征">（二）基本思想和特征：</h3>
<p>分治策略：对于一个规模为n的问题，若可直接解决则直接解决，否则将其分解为k个规模较小的子问题，子问题之间要互相独立且与原问题形式相同，递归解决子问题后，可以将其合并得到原问题的解。</p>
<p>递归求解时，子问题的规模应当继续缩小，直到到达可以直接处理的基本情况。需要递归处理的子问题个数由算法决定；例如二分查找只继续处理其中一半。</p>
<p>以归并排序为例，左右两半可以分别排序，随后再合并。这里关注的是子问题如何组成原问题，以及求解过程中是否重复处理同一个子问题。</p>
<p>形式相同是说子问题仍属于同一类问题：排序数组的一半，得到的仍然是排序问题。求最优值时还需要分析最优解与子问题解的关系，不能仅凭问题形式相同就认定具备最优子结构。</p>
<p>分治法的使用特征一般为：</p>
<ol>
<li>规模足够小时，可以直接求解，并有明确的递归终止条件。</li>
<li>原问题能够转化为规模更小的同类问题。</li>
<li>得到子问题的解后，能够据此求出原问题的解。</li>
<li>检查是否会反复求解同一个子问题；如果存在重复，可以考虑保存并复用已经得到的结果。</li>
</ol>
<span id="基本步骤" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-基本步骤">基本步骤：</h3>
<p>下面用递归过程描述分治。</p>
<p>对于每一层的递归分治法都有以下三个步骤：</p>
<ul>
<li>分解：将原问题分解为k个规模较小，相互独立，与原问题形式相同的子问题。</li>
<li>解决：若子问题规模较小而容易被解决则直接解决，否则递归地解各个子问题。</li>
<li>合并：将各个子问题的解合并为原问题的解。</li>
</ul>
<span id="分治法的复杂性分析" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-分治法的复杂性分析">分治法的复杂性分析：</h3>
<p>分治法将规模为n的问题分成a个规模为n/b的子问题去求解，直到n达到分解阈值以下时才可以直接求解。</p>
<p>设基本情况为 <code>T(1) = Θ(1)</code>；一层中产生 <code>a</code> 个规模约为 <code>n/b</code> 的递归子问题，其余拆分、合并操作共花费 <code>F(n)</code> 时间，则递推式为 <code>T(n) = aT(n/b) + F(n)</code>。这里要求 <code>a ≥ 1</code>、<code>b > 1</code>。</p>
<p>例如归并排序递归处理两个半长数组，再在线性时间内合并，得到 <code>T(n) = 2T(n/2) + Θ(n)</code>。原文此处的图片已缺失，上述文字公式是本次整理时依据 <a href="https://live.ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/1869dbf640ded6b31f1bd369d2001ef5_MIT6_006S20_r03.pdf" rel="noopener noreferrer">MIT 6.006 Recitation 3，第4–6页</a>重新编写的。</p>
