2d:T2cee,<span id="纯虚函数和抽象类" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-纯虚函数和抽象类">纯虚函数和抽象类：</h3>
<span id="一概念" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-一概念">（一）概念：</h4>
<ul>
<li>
<p>纯虚函数：</p>
<p>纯虚函数是在类内的虚函数声明末尾加上 <code>= 0</code> 的函数，用于声明需要由具体类完成的接口。派生类可以继续保持抽象；只有最终重写版本不再是纯虚函数时，才满足这一项实例化条件。</p>
<p>纯虚函数也可以有定义，但定义应单独放在类外，不能在带 <code>= 0</code> 的同一个声明中同时写函数体。类外定义不会取消它的纯虚属性；派生类可用限定名调用这份公共实现。</p>
<p>如果析构函数声明为纯虚函数，创建该类或派生类对象时仍需提供析构函数定义，供析构过程使用。</p>
<p>纯虚函数格式：<code>virtual 返回类型 函数名(参数表) = 0;</code></p>
</li>
<li>
<p>抽象类：</p>
<p>只要还有某个纯虚函数的最终重写版本仍为纯虚函数，这个类就是抽象类。抽象类可以用来表达接口，也可以同时包含数据成员和已实现的操作。</p>
<p>抽象类把相关操作组织在一个继承层次中，为派生类提供公共接口。派生类可以实现这些操作，也可以把尚未实现的接口继续交给下一层派生类。</p>
</li>
</ul>
<span id="二抽象类的限制" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-二抽象类的限制">（二）抽象类的限制：</h4>
<ul>
<li>抽象类不能创建独立的完整对象，但可以作为具体派生类对象中的基类子对象。</li>
<li>派生类可以继承上一层已有的重写实现；只要还存在最终重写版本为纯虚函数的操作，它就仍是抽象类。</li>
<li>可以声明抽象类类型的指针和引用，用来访问具体派生类对象中的基类部分。</li>
<li>不能定义或调用以抽象类作为按值参数或按值返回类型的函数；使用指针或引用则可以。</li>
<li>抽象类类型可以用于 <code>sizeof</code>，但这不会创建抽象类对象。</li>
</ul>
<span id="三接口继承和实现继承" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-三接口继承和实现继承">（三）接口继承和实现继承：</h4>
<p>接口继承让派生类遵守基类约定的操作；实现继承让派生类复用已有函数体。两者可以同时存在。</p>
<p>普通虚函数既提供可重写的接口，也可以提供默认实现。派生类没有重写时，会继续使用继承的实现。纯虚函数则让尚未完成接口的类保持抽象，即使它在类外有定义也是如此。</p>
<p>需要通过基类接口执行不同派生类行为时，可以把对应操作设计为虚函数；普通的实现复用不必一律使用虚函数。</p>

<span id="异质链表" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-异质链表">异质链表：</h3>
<h4 id="section-一概念-1">（一）概念：</h4>
<p>用基类类型指针（抽象类类型指针也可以），可以生成一个连接不同派生类对象的动态链表。</p>
<p>每个结点指针可以指向类层次中不同的派生类对象，这种结点类型不相同的链表被称为异质链表。</p>
<span id="二限制" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-二限制">（二）限制：</h4>
<ul>
<li>这里讨论的是使用基类指针连接对象的实现，不同节点类型需要有一个可访问、无歧义的共同基类；各派生类之间不必相互继承。</li>
<li>可以有多层继承关系，只要节点能通过共同的基类接口访问。</li>
<li>节点指针使用共同基类类型；<code>new</code> 后必须是可实例化的具体类型，抽象基类本身不能用于创建对象。</li>
<li>输出方法可以是各个类的自己成员函数或友元函数，或者是另写一个输出方法。</li>
</ul>
