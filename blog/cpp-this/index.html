c++类——this指针

从成员函数如何定位调用对象的问题出发，介绍 this 指针及显式使用它的代码

（一）引言:

在c++中，我们在类中创建成员函数，在创建类的对象后，在类的对象上使用类的成员函数可以访问类的此对象的数据。

那么这个成员函数是怎么知道要访问的是此对象的数据成员，而不是其他对象的呢？

调用本文这种非静态成员函数时，this 指向发起调用的对象。成员函数通过这个指针访问该对象的数据成员。

下面对this指针进行详细介绍。

（二）概念:

本文讨论使用隐式对象参数的非静态成员函数。在类 X 的普通成员函数中，this 是类型为 X* 的指针纯右值；在 const 成员函数中，它的类型为 const X*，其他 cv 限定同样作用于所指类型。

this 不能作为赋值的左操作数。它表示当前对象的地址，成员函数中可以用 this->成员 访问当前对象。

调用 s.resetXY(2, 3) 时，调用对象是 s，函数内的 this 指向 s。这个关联由成员函数调用规则确定；函数声明中的参数仍然只有 a 和 b。

例子如下：

c++
#include <iostream>
using namespace std;
class Simple
{
private:
	int x;
	int y;
public:
	Simple() = default;
	Simple (int a, int b) : x(a), y(b)
	{
		cout << "Finish the constructed function" << endl;
	}
	void resetXY(int a, int b) 
	{
		x = a,y = b;
		return ;
	}
	~Simple()
	{
		cout << "Finish deconstructor" << endl;
	}
};
int main()
{
	Simple s(1, 2);
	s.resetXY(2, 3); //此时 resetXY 内的 this 指向 s
	                 //成员 x、y 分别属于当前对象 s
    return 0;
}

（三）this指针的注意要点:

  1. this 是指针纯右值，不能给 this 本身赋值。

  2. this 可以用于本文这种成员函数的函数体，也可以用于标准允许的声明位置和非静态数据成员的默认初始化器。

  3. 多个对象调用同一成员函数时，函数中的 this 分别指向各自的调用对象。

  4. 静态成员函数以及采用显式对象参数的成员函数不能使用 this。普通非成员友元函数也没有当前对象的 this。

    静态成员函数的对象关系详见 c++类——静态成员。

  5. this 可以显式使用，例如 this、(*this).x、this->x；其中 x 是当前对象的数据成员。

  6. this 表达式不会为每个对象增加一个指针数据成员，因此不会增加该类对象的 sizeof。

（四）this指针的显式使用样例:

c++
#include <iostream>
using namespace std;
class Simple
{
private:
	int x;
	int y;
public:
	Simple() = default;
	Simple (int a, int b) : x(a), y(b)
	{
		cout << "Finish the constructed function" << endl;
	}
	void resetXY(int a, int b) 
	{
		x = a, y = b;
		return ;
	}
	void Simple_thisuse(int a,int b)
	{
		cout << this->x << " " << this->y << endl;
		(*this).x += a;
		(*this).y += b;
		cout << this->x << " " << this->y << endl;
		cout << this << endl;
		return;
	}
	~Simple()
	{
		cout << "Finish deconstructor" << endl;
	}
};
int main()
{
	Simple s(1, 2);
	s.resetXY(2, 3);
	s.Simple_thisuse(1, 1);
	return 0;
}
