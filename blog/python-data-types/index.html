python基础——数据类型（一）简介

整理常见数据类型，并以对象身份的示例讨论可变类型与不可变类型

1.概念：

python中的数据类型主要是指变量所指的内存中对象的类型。

变量名绑定到对象，对象本身具有类型，可以用 type() 查看。给变量重新赋值，可能让它改为引用另一个对象。

2.分类：

这里先介绍 Python 中六类常见的数据类型：

  • Number（数字） 包括整型、浮点型、复数型和布尔型
  • String（字符串）
  • List（列表）
  • Tuple（元组）
  • Set（集合）
  • Dictionary（字典）

其中Number、String和Tuple是不可变数据类型，而List、Dictionary和Set是可变数据类型。

3.可变数据类型与不可变数据类型：

可变性描述对象创建后，其内容能否被修改。列表可以在原对象上增删元素；整数对象的值不能被修改。重新给变量赋值改变的是名称绑定，不能据此判断对象是否可变。

例如下面的 a = 2 让 a 改为引用整数 2，原先的整数 1 并没有被修改。id() 返回对象身份标识；CPython 将它实现为内存地址。

text
a=1
print(id(a))
a=2
b=2
print(id(a))
print(id(b))
# 输出结果：
# 140733592564520
# 140733592564552 a引用的对象改变了
# 140733592564552 本次记录中b和a引用同一个对象。
