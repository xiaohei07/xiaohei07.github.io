27:T9ad,<span id="1概念" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-1概念">1.概念：</h3>
<p>python中的数据类型主要是指变量所指的内存中对象的类型。</p>
<p>变量名绑定到对象，对象本身具有类型，可以用 <code>type()</code> 查看。给变量重新赋值，可能让它改为引用另一个对象。</p>
<span id="2分类" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-2分类">2.分类：</h3>
<p>这里先介绍 Python 中六类常见的数据类型：</p>
<ul>
<li>Number（数字） 包括整型、浮点型、复数型和布尔型</li>
<li>String（字符串）</li>
<li>List（列表）</li>
<li>Tuple（元组）</li>
<li>Set（集合）</li>
<li>Dictionary（字典）</li>
</ul>
<p>其中Number、String和Tuple是不可变数据类型，而List、Dictionary和Set是可变数据类型。</p>
<span id="3可变数据类型与不可变数据类型" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-3可变数据类型与不可变数据类型">3.可变数据类型与不可变数据类型：</h3>
<p>可变性描述对象创建后，其内容能否被修改。列表可以在原对象上增删元素；整数对象的值不能被修改。重新给变量赋值改变的是名称绑定，不能据此判断对象是否可变。</p>
