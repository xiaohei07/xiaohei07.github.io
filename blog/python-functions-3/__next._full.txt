<p>Python是面向对象的程序设计语言，也是面向过程的程序语言,同时也支持函数式编程。</p>
<p>Pyhon标准库functools 提供了若干关于函数的函数，提供了Haskell和Standard ML中的函数式程序设计工具。</p>
<p>Python中的函数与其他数据类型处于平等地位，因此函数可以赋值给变量，可以作为参数传入其他函数，存储在其他数据结构中，或者作为函数的返回值。</p>
<span id="1-作为对象的函数" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-1-作为对象的函数">1. 作为对象的函数：</h4>
<p>函数在Python中是作为对象存在的，故函数对象可以赋值给变量，然后调用该变量。</p>

<p>数据结构内的函数：函数作为对象，也可以存储数据结构内部。</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>def fun1():

<span id="2-map-filter-和-reduce" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-2-mapfilter-和-reduce">2. Map、Filter 和 Reduce:</h4>
<span id="1-map函数" class="legacy-anchor" aria-hidden="true"></span><h5 id="section-1-map函数">(1) map函数：</h5>
<p>map 函数的功能是对可迭代对象中的每个元素都调用指定的函数，并返回一个map对象的iterator迭代器（可以转化为list对象）。</p>
<p>语法格式：<em><strong>map(function, iterable)</strong></em></p>
<p>function参数表示传入的函数，可以是内置函数、自定义函数或者 lambda 匿名函数，iterable表示可迭代对象，可以是列表、元组等，允许一到多个。</p>
<p>一般用于对某个集合对象的全部值执行某个特定操作。</p>
<p>map() 函数由 C 语言实现，执行效率高。</p>
<p>例子如下：</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>list_use = [1,2,3,4,5,6,7,8,9]
list_new = list(map(lambda x:x*2, list_use))
print(list_new)
# 运行结果：
# [2, 4, 6, 8, 10, 12, 14, 16, 18]
</code></pre></div>
<span id="2-fiter函数" class="legacy-anchor" aria-hidden="true"></span><h5 id="section-2-fiter函数">(2) fiter函数：</h5>
<p>filter函数的功能是对传入的可迭代对象中的每个元素，都进行函数判断，并返回True或者False，最后将返回 True 的元素组成一个新的可遍历的集合对象，返回其迭代器。</p>
<p>语法格式：<em><strong>filter(function, iterable)</strong></em></p>
<p>function参数表示传入的函数，可以是内置函数、自定义函数或者 lambda 匿名函数，iterable表示可迭代对象，可以是列表、元组等，允许一到多个。</p>
<p>一般用于筛除可迭代对象的不想要的项。</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>list_use = [1,2,3,4,5,6,7,8,9]
list_new = list(filter(lambda x:x%2==0, list_use))
print(list_new)
# 运行结果：
# [2, 4, 6, 8]
</code></pre></div>
<span id="3redeuce函数" class="legacy-anchor" aria-hidden="true"></span><h5 id="section-3redeuce函数">（3）redeuce函数：</h5>
<p>reduce() 函数通常用来对一个集合做一些累积操作。</p>
<p>语法格式：<em><strong>reduce(function, iterable)</strong></em></p>
<p>function规定必须传入一个包含 2 个参数的函数；iterable 表示可迭代对象，可以是列表、元组等，允许一到多个。</p>
<p>reduce() 函数在Python 3.x 中已经从内置函数中被移除，在functools模块使用 ，需要导入functools模块。</p>
<p>reduce 函数一般用于总结或者概述数据集。</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>import functools
list_use = [3,4,5,6,7]
list_new = functools.reduce(lambda x,y:x+y, list_use)
print(list_new)
# 运行结果：
# 25
</code></pre></div>
<span id="3-函数装饰器" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-3-函数装饰器">3. 函数装饰器：</h4>
<span id="1闭包" class="legacy-anchor" aria-hidden="true"></span><h5 id="section-1闭包">（1）闭包：</h5>
<p>是指在函数中嵌套其他函数时引用外部函数变量，即在一个内部函数中，对外部作用域的变量进行引用，内部函数即为闭包。</p>
<p>一般情况下，内部函数是外部函数的返回值。</p>
<p>闭包无法修改外部函数的局部变量。</p>
<p>举例：</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>def add_two(a):
    def add_new(b):
        return a+b
    return add_new
print(add_two(2)(3))
# 运行结果：
# 5
</code></pre></div>
<span id="2装饰器" class="legacy-anchor" aria-hidden="true"></span><h5 id="section-2装饰器">（2）装饰器：</h5>
<p>是闭包的一个应用，能够使得代码更简短。</p>
<p>装饰器是用于拓展原函数功能的一种函数，不需要修改原函数的内容和调用。</p>
<p>装饰器常用于授权、日志等行为。</p>
<p>语法格式：</p>
<p><strong>def 装饰器函数名(唯一形参):</strong></p>
<p>​	<strong>函数体</strong></p>
<p><strong>@装饰器函数名</strong></p>
<p><strong>def 被装饰的函数名(形参列表):</strong></p>
<p>​	<strong>函数体</strong></p>
<p>使用时直接调用被装饰的函数名即可。</p>
<p>装饰器函数的形参需要一个函数作为参数传入，同时需要在内部代码块执行该函数，以保证被装饰函数的正确执行。</p>
<p>传参时和带参数时需要装饰器函数嵌套函数，后面进行介绍。</p>
<p>Python内置了3种函数装饰器，分别是＠staticmethod、＠classmethod 和@property，我们也可以自己定义函数装饰器。</p>
<p><strong>装饰器完成的内容：</strong></p>
<ul>
<li>将被装饰的函数作为参数传给装饰器函数（后面->前面）。</li>
<li>将被装饰的函数的返回值替换成装饰器函数的返回值（前面->后面）。</li>
</ul>
<p>实际上，就是把装饰器函数的功能按一定逻辑顺序加入到被装饰的函数当中，使得原函数不需要修改。</p>
<p>因此，不用@函数也可以完成装饰器的功能，只是相对而言阅读比较困难。</p>
<p>例子如下：</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>def use_decorator_fun(used_for_decorator_fun):
    print("添加新功能的位置，在被装饰的函数执行之前执行")

    print("添加新功能的位置，在被装饰的函数执行之后执行")
    return True
@use_decorator_fun
def used_for_decorator_fun():

    print("\n执行完毕")

result = used_for_decorator_fun
if result:

# 执行正常功能中
# 1,3,5,7,9,
# 执行完毕
# 添加新功能的位置，在被装饰的函数执行之后执行
# 执行成功

</code></pre></div>
<p>如果不用@，可以是以下形式来表示：</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>def use_decorator_fun(used_for_decorator_fun):

<p>可以看到，@use_decorator_fun只是换成了used_for_decorator_fun =use_decorator_fun(used_for_decorator_fun)，不过此句的位置换到了两个函数定义之后。</p>
<p>这就是装饰器的实质。</p>
<span id="3装饰器传参" class="legacy-anchor" aria-hidden="true"></span><h5 id="section-3装饰器传参">（3）装饰器传参：</h5>
<p>被装饰的函数带有参数时，需要对装饰器函数进行处理，以便前者为后者传递参数。</p>
<p>此时，需要为装饰器函数增加一个嵌套函数，嵌套的内部函数带有形参列表，如果其接收参数数量确定可以直接指定好形参列表数量，但多数时候参数数量是不固定的，此时使用前文已讲述的过的两个参数*args和**kwargs来完成接收任意数量参数的要求。</p>

<p>装饰器除了接收原函数任意类型和数量的参数，还可以接收自己定义的参数。</p>
<p>此时，需要在装饰器函数外部额外嵌套一层函数，该层负责接收自己定义的参数，内部代码块的对应return也要添加。</p>
<p>同时，在@处需要在函数名后增加要传入的实参，注意，此处必须传入对应参数。</p>
<p>例子如下：</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>def fun_use_parameter(a,b):
    def fun_use_add(fun_use):
        def fun_use_add_fact(*args,**kwargs):
            print("添加新功能的位置，在被装饰的函数执行之前执行")

                print("第"+str(i)+"次执行函数功能,函数功能序号为"+str(b))

            print("添加新功能的位置，在被装饰的函数执行之后执行")
