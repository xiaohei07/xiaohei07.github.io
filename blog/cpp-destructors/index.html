（一）概念:

析构函数是一个特殊的成员函数。

析构函数在对象销毁时执行资源清理。例如，自动存储期的局部对象在离开作用域时会析构，delete 一个由 new 创建的对象也会调用它的析构函数。显式调用析构函数会结束对象的生命周期，但不会因此释放该对象本身的存储空间；存储空间的释放由相应的存储管理操作负责。

（二）特性：

  • 析构函数的形式是：~类名(){ 析构函数体 }，其中 ~ 是析构函数名的组成部分。
  • 析构函数无参数，也无返回值。
  • 析构函数没有参数，因此不能通过不同的参数列表来重载。
  • 对本文这种普通类，用户未声明析构函数时，编译器会隐式声明默认析构函数。它会按规则析构非静态类类型成员及基类；原始指针成员不会自动 delete 所指向的堆对象。若成员或基类的析构函数被删除或不可访问，默认析构函数也可能被定义为删除（deleted）。
  • 已完成初始化的静态局部对象不会在每次函数返回时析构；正常程序终止时才执行其析构函数。
  • 对 new 创建并由原始指针管理的对象，通常用 delete 触发析构并释放存储空间。指针变量离开作用域不会自动完成这些操作。

（三）代码实现：

text
#include <iostream>
using namespace std;
class Time
{
private:
	int hour;  
	int minute;
	int sec;
	int* p;//动态指针使用
public:
	Time() { hour = minute = sec = 0; p = new int(10); }
	Time(int i1, int i2, int i3) :hour(i1), minute(i2), sec(i3) { p = new int(10); }
	~Time() 
	{
		cout << "执行析构函数" << endl;
		if (p != NULL) {
			delete p;
			p = NULL;
		}//如果没有这句话，系统不会对动态指针指向内存空间进行释放，可能会发生内存泄漏
	}
	void set_time()
	{
		cin >> hour >> minute >> sec;
		return;
	}
	void show_time()
	{
		cout << hour << ":" << minute << ":" << sec << endl;
	}
};
int main()
{
	Time t1(4, 5, 6);
	t1.show_time();
	return 0;//执行析构函数
}
