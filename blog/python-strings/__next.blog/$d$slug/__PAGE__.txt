27:T1982,<span id="一概述" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-一概述">（一）概述：</h3>
<p>字符串类型，也是文本序列类型，是Python中最常用的类型，在Python中是str类型。</p>
<p>在Python3.x版本中，字符串全部是由Unicode国际码构成的，是一个不可变序列，其存储位数全部为16位，不再有8位的ASCII码存储了。</p>
<p>但是如果需要在网络上传输或者保存到磁盘，这个序列需要变成以字节为单位的bytes。对于Python来说，bytes类型的数据只需要在字符串前面加上b前缀即可。</p>
<p>Unicode表示的str通过encode()方法可以编码为指定bytes，而bytes变为str可以统decode()方法转换。</p>
<p>注意：python中没有字符类型，单个字符默认为字符串类型。</p>
<p>格式化内容请参考<a href="/blog/python-input-output/">python基础——输入和输出详解</a></p>
<p>本文无字符串函数讲解（太多了），可能以后会再补充博客进行单独说明~</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>a = "我"

# 输出结果：
# 我   &#x3C;class 'str'>
# b'\xe6\x88\x91'   &#x3C;class 'bytes'>

</code></pre></div>
<span id="二形式" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-二形式">（二）形式：</h3>
<ol>
<li>单引号，形式为 <em><strong>'字符串内容 '</strong></em>，单引号内允许含有双引号。</li>
<li>双引号，形式为 <em><strong>"字符串内容 "</strong></em>，双引号内允许含有单引号。</li>
<li>三引号且均为单/双引号，此为长字符串，形式为 <em><strong>'''字符串内容 "'</strong></em>或者是<em><strong>"""字符串内容 """</strong></em>，此内容可以跨越多行，而且允许字符串包含换行符、制表符、单双引号（不会冲突）以及其他特殊字符，所有的空白字符也将包含在该字符串中。</li>
</ol>

<span id="三原始字符串" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-三原始字符串">（三）原始字符串：</h3>
<p>在字符串或者长字符串的开头加上r/R前缀，字符串将会变为原始字符串。</p>
<p>在原始字符串中，反斜杠不再是转义字符，所有内容均保持不变。</p>
<p>但如果出现引号，反斜杠仍然会对引号进行转义，这会导致如果是结尾处出现反斜杠，会将后面的引号转义，导致没有结束引号而产生错误，且这个反斜杠没有办法转义自己，无法断开与后面引号的练习。</p>
<p>解决方法：利用字符串拼接，将最后一个\放到另一个非原始字符串中然后进行拼接即可。</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>a = r"\n\n\n\n\n"

c = r'\\aaa'
d = r"D:\pycharmwork"+"\\"
print(a)
print(b)
print(c)
print(d)
# 输出结果：
# \n\n\n\n\n
# abcd\t
# \\aaa
# D:\pycharmwork\
</code></pre></div>
