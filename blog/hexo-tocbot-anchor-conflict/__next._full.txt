1c:T2f44,<span id="问题说明" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-问题说明">问题说明</h3>
<p>在使用hexo部署博客时，使用了<a href="https://hexo.fluid-dev.com/" rel="noopener noreferrer">fluid主题</a>，该主题可以使用<a href="https://github.com/tscanlin/tocbot" rel="noopener noreferrer">tocbot</a>在右侧生成一个跳转的目录，如下：</p>
<p><img src="https://s21.ax1x.com/2024/07/16/pkIezKH.png" alt="image-20240716091527332" width="383" height="286" loading="lazy" decoding="async" referrerpolicy="no-referrer"></p>
<p>为了使用更强的markdown渲染器，选择将hexo默认markdown渲染器的hexo-renderer-marked卸载，转而安装 <a href="https://github.com/hexojs/hexo-renderer-markdown-it" rel="noopener noreferrer">hexo-renderer-markdown-it</a>，该渲染器支持在<code>&#x3C;hi></code>标签上<strong>自动生成标题锚点，并自动生成标题id</strong>，该标题id即可用于tocbot自动扫描，并为右侧的目录生成跳转链接，保证右侧目录的正确跳转</p>
<p>但为了在文章正文中插入目录（一般是开头），需要其他的插件的支持，考虑到<a href="https://github.com/medfreeman/markdown-it-toc-and-anchor" rel="noopener noreferrer">markdown-it-toc-and-anchor</a>现在已不再维护，其使用的markdown-it版本太低，故添加插件<a href="https://github.com/bubkoo/hexo-toc" rel="noopener noreferrer"><strong>hexo-toc</strong></a>用于<strong>生成标题锚点和文章目录</strong>（标题锚点请在hexo-renderer-markdown-it和hexo-toc中二选一），该插件只需要在markdown文章中任意位置添加<code>&#x3C;!-- toc --></code>即可生成目录</p>
<p>但是，同时使用二者导致了一个特殊的bug，<strong>即右侧的tocbot目录的跳转只能回到文章页面的顶部，无法正确跳转到标题位置</strong>，通过浏览器的F12检查得知了其原因：</p>
<img src="https://s21.ax1x.com/2024/07/16/pkIm1iV.png" alt="image-20240716092938088" width="982" height="116" loading="lazy" decoding="async" referrerpolicy="no-referrer">
<p><img src="https://s21.ax1x.com/2024/07/16/pkImwIx.png" alt="image-20240716092903108" width="536" height="84" loading="lazy" decoding="async" referrerpolicy="no-referrer"></p>
<p>这里可以看到，&#x3C;h3>目录并未像预期的那样生成id，而是添加了一个<code>&#x3C;span></code>标签，并在其中生成了标题id，这使得tocbot的扫描结果变成了如下的情况：</p>
<p><img src="https://s21.ax1x.com/2024/07/16/pkImGzF.png" alt="image-20240716093158727" width="1009" height="349" loading="lazy" decoding="async" referrerpolicy="no-referrer"></p>
<p>通过<strong>标题跳转的超链接标签&#x3C;a title>中的href=“#”可知，tocbot生成的标题超链接只能回滚到页面顶部，无法跳转到指定的目录标题位置，而这正是因为标题id位于&#x3C;span>标签，无法被tocbot获得所导致的</strong>，此时，只能通过tocbot中的标题锚点，即“¶”完成正确跳转</p>
<p><span id="correct_html" class="legacy-anchor" aria-hidden="true"></span><span id="user-content-correct_html"> </span><strong>如果需要tocbot正常工作，标题处的html结构和tocbot的html结构应如下</strong>：</p>
<img src="https://s21.ax1x.com/2024/07/16/pkImDJK.png" alt="image-20240716094617125" width="528" height="112" loading="lazy" decoding="async" referrerpolicy="no-referrer">
<p><img src="https://s21.ax1x.com/2024/07/16/pkIm6Qe.png" alt="image-20240716094654457" width="951" height="259" loading="lazy" decoding="async" referrerpolicy="no-referrer"></p>
<p>观察可知，<strong>在&#x3C;h3>标签中生成了标题的id，而不是在一个span标签中，进而tocbot在扫描后可以在自动目录中正确生成对应的href链接，指向该标题id，此时的点击应能正确跳转</strong></p>
<span id="问题解决" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-问题解决">问题解决</h3>
<p>在本人尝试了多种方法后，最终在github的issue区<a href="https://github.com/YenYuHsuan/hexo-theme-beantech/issues/11" rel="noopener noreferrer">Content's link show 'undefine' · Issue #11 · YenYuHsuan/hexo-theme-beantech (github.com)</a>中，看到了 <a href="https://github.com/fawks96" rel="noopener noreferrer">fawks96</a> 这位大佬的回复，并以此解决了问题：</p>
<p><img src="https://s21.ax1x.com/2024/07/16/pkImNL9.png" alt="image-20240716094108934" width="973" height="919" loading="lazy" decoding="async" referrerpolicy="no-referrer"></p>
<p>这里的代码位于博客目录下的<code>node_modules\hexo-toc\lib\filter.js</code>文件内，打开后如下：</p>
<p><img src="https://s21.ax1x.com/2024/07/16/pkImdd1.png" alt="image-20240716094343221" width="981" height="629" loading="lazy" decoding="async" referrerpolicy="no-referrer"></p>
<p>代码说明如下</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>// 为$title元素设置一个id属性，属性值为变量id的值。
$title.attr('id', id);

// 移除标题元素$title下的所有直接子元素中的&#x3C;a>标签，即：如果标题元素$title的子元素中包含&#x3C;a>标签，这些&#x3C;a>标签会被从html结构中移除
$title.children('a').remove();
// 将标题元素$title 的HTML内容包裹在一个&#x3C;span>元素内，并设置这个 &#x3C;span> 元素的 id 属性为变量id的值
$title.html( '&#x3C;span id="' + id + '">' + $title.html() + '&#x3C;/span>' );
// 移除标题元素$title上的id属性
$title.removeAttr('id');
</code></pre></div>
<p>从这里可以看出，<strong>hexo-toc在更新后直接移除了标题中的id和子元素中的超链接，改为添加&#x3C;span>标签，这里没有考虑其他插件的工作过程和效果，因此最终导致了问题的发生</strong></p>
<p>解决方法也很简单，直接修改源码(回滚版本)，即可：</p>
<p><img src="https://s21.ax1x.com/2024/07/16/pkIMYfx.png" alt="image-20240716100825645" width="781" height="185" loading="lazy" decoding="async" referrerpolicy="no-referrer"></p>
<p>重新部署，可以看到其效果如<a href="/blog/hexo-tocbot-anchor-conflict/#correct_html">上面的正确结构</a>所示，且所有跳转均恢复正常</p>
