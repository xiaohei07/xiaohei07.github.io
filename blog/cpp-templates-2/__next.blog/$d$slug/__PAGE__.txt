12:T6167,<span id="一函数模版" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-一函数模版">（一）函数模版：</h3>
<p>重载函数通常基于不同的数据类型实现类似的操作，对不同数据类型有完全相同的操作，用函数模版实现更为简介方便。</p>
<span id="1-格式与定义" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-1-格式与定义">1. 格式与定义：</h4>
<p>　<em><strong>template &#x3C;类型形式参数表></strong></em>
　<em><strong>返回类型 函数名(参数列表) { 函数体 }</strong></em></p>
<p>类型形式参数表= <em><strong>class T<sub>1</sub>, class T<sub>2</sub>, ... , class T<sub>n</sub></strong></em> or  <em><strong>typename T<sub>1</sub>, typename T<sub>2</sub>, ... , typename T<sub>n</sub></strong></em></p>
<p>函数模版定义由模版说明和函数定义构成。</p>
<p>模版说明的类属参数必须在函数定义中至少出现一次。</p>
<p>函数参数表中可以使用类属类型参数，也可以使用一般类型参数。</p>
<p>函数模板不允许自动类型转化。</p>
<p>其他要点前文已有讲述，此处不再重复。</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>#include&#x3C;iostream>

	return left == right;

	cout &#x3C;&#x3C; IsEqual&#x3C;int>(1, 1.2) &#x3C;&#x3C; endl;    // 显式实例化

<span id="2-重载函数模版" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-2--重载函数模版">2.  重载函数模版：</h4>
<p>当模版类型不能满足需要（不能提供类型的隐式转换）时，函数模版可以进行重载（效果和普通的函数重载一致），而且可以和普通重载函数并存。</p>
<p>此时如果均存在匹配，涉及到了匹配的优先级关系，为此，c++的函数模版有匹配约定：</p>
<ul>
<li>寻找和使用最符合函数名和函数类型的普通函数，若找到则调用它。</li>
<li>否则寻找一个函数模版，将其实例化产生一个匹配的函数参数，若找到则调用它。</li>
<li>否则，寻找可以通过类型转换进行参数匹配的重载函数，若找到则调用它。</li>
<li>如果前三次的寻找均为找到匹配函数，则调用错误；如果在三次的某次寻找中调用有多余一个的匹配选择，则调用匹配出现二义性。</li>
</ul>

<span id="二类模版" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-二类模版">（二）类模版：</h3>
<p>类模版用于实现类所需数据的类型参数化。</p>
<p>类模版在表示如数组、表、图等数据结构上显得特别重要，这些数据结构的表示和算法不受所包含的元素类型的影响。</p>
<span id="1-格式" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-1-格式">1. 格式：</h4>
<p><em><strong>template&#x3C;类型形式参数表></strong></em>
<em><strong>class 类名{ ... };</strong></em></p>
<p>类属参数可以用于声明类中的成员变量和成员函数，在类中使用内置雷类型的地方也都可以用类属参数来声明。</p>
<p>另外，类模版中的成员函数放到类模版定义外面写时的语法有限制：</p>
<p><em><strong>template&#x3C;类型形式参数表></strong></em></p>
<p><em><strong>返回值类型 类模板名&#x3C;类型参数名列表>::成员函数名(参数表) { 函数体 }</strong></em></p>
<p>创建对象的格式：</p>
<p><em><strong>类模板名&#x3C;真实类型参数表> 对象名(构造函数实际参数表);</strong></em></p>
<p>如果有无参构造函数，可以是：</p>
<p><em><strong>类模板名&#x3C;真实类型参数表> 对象名;</strong></em></p>
<p>注意：类模版形参不存在实参推演的问题，不能给真实类型参数表传递实参，只能传递类型。</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>#include&#x3C;iostream>

<span id="2-类模版作为函数参数" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-2-类模版作为函数参数">2. 类模版作为函数参数：</h4>
<p>函数的形式参数类型可以是类模版或类模版的引用，对应的实际参数是该类模版实例化的模版类对象。</p>
<p>因此，只有函数模版能够拥有模版类参数。</p>

<span id="3-模板类和类模板" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-3-模板类和类模板">3. 模板类和类模板：</h4>
<p>类模板是模板的一种，可以在使用确定类属参数。</p>
<p>类模板不是一个类，不会生成对象，也不会占据空间。</p>
<p>模板类是类模板的一个实例，是确定了类属参数的具体类，可以直接生成对象。</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>//模板类:

<span id="4-函数模板作为类模版成员" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-4-函数模板作为类模版成员">4. 函数模板作为类模版成员：</h4>
<p>类模板中的成员函数还可以是一个函数模板成员，函数模板只有在被调用时才会被实例化。</p>
<p>无论是原则还是声明，模板语法的优先级是最高的，不同模板的优先级先根据其声明顺序来判断，其次是函数修饰，然后是返回值。</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>#include &#x3C;iostream>

<span id="5-类层次中的类模版" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-5-类层次中的类模版">5. 类层次中的类模版：</h4>
<p>在类层次中，类模板可以是基类，也可以是派生类。</p>
<p>类模板可以从类模板或普通类派生：</p>
<ul>
<li>当一个类模板从普通类派生时，意味着派生类增加了类属参数。</li>
<li>当一个类模板从类模板派生时，可以添加新的类属参数，也可以保持，同时其他性质和一般的类之间的派生性质相同。</li>
</ul>
<p>普通类可以从模板类或普通类派生：</p>
<ul>
<li>当一个普通类从类模板派生时，意味着派生类继承基类时，需要提供实例化的类型参数使派生的普通类内没有类属参数，同时需要编译分配内存。</li>
<li>普通类之间的派生不涉及模板。</li>
</ul>
<p>类模板之间允许有多继承关系（性质简单，此略）。</p>
<div class="code-block"><div class="code-toolbar"><span>text</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code>#include &#x3C;iostream>

<span id="6-类模版和友元" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-6-类模版和友元">6. 类模版和友元：</h4>
<p>模板类的友元分三类：</p>
<p>1，非模板友元。</p>
<p>2，约束模板友元，即友元的类型取决于类被实例化时的类型。</p>
<p>3，非约束模板友元，即友元的所有具体化都是类的每一个具体化的友元。</p>
<ul>
<li>一个函数或函数模板或函数模板的实例化（这个函数可以是某个类的成员函数）可以是类或类模板的友元——这会使其成为由该类模板实例化的每个类模板的友元函数。</li>
<li>一个类或类模板或者一个类模板的实例化可以是类或类模板的友元类——逻辑同上。</li>
</ul>
<p>所有友元中的函数的参数或者返回值可以是该模板类的类属参数。</p>

<span id="7-类模版和static成员" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-7-类模版和static成员">7. 类模版和static成员：</h4>
<p>从类模版实例化的每个模版类有自己的类模版数据成员，该模版类的所有对象共享一个static数据成员。</p>
<p>每个模版类有自己的类模板的static数据成员副本，这之间不是直接共享的。</p>
<p>和非模版类的static数据成员一样，模版类的static数据成员也应该在文件范围定义和初始化。</p>
<p>static数据成员可以用类属参数对应的类型声明，在外部定义时无需赋值，但是需要在前面说明template和类属参数表，以对类模版的相关模版类进行定义，这些static成员在创建模版类时自动默认初始化（如int则初始化为0，等等）。</p>

template&#x3C;class T>
class A
{
protected:
	T val;
	//int类型:
	static int totalcount;
	//抽象类型
	static T totalval;
public:

	A(T v) :val(v) { totalcount += 1; totalval += val; }
	static T gettotalval() { return totalval; }
	static int gettotalcount() { return totalcount; }
	T getval() { return val; }
	~A() { totalcount -= 1; totalval -= val; }
};
