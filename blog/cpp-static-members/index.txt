1c:T21cf,<span id="一概念" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-一概念">（一）概念:</h3>
<p>类成员冠以static声明时，称为静态成员。静态成员用于解决类内数据共享的问题，既能够避免使用全局变量，又能够让同类的多个对象数据共享。</p>
<p>如果使用全局变量对封装的类来说并不安全，因为其他的类外函数能共享、修改全局变量，同时容易发生名字的冲突问题。</p>
<p>静态成员包括静态数据成员和静态成员函数。</p>
<p>下面分别介绍。</p>
<span id="二静态数据成员" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-二静态数据成员">（二）静态数据成员：</h3>
<span id="1-概念" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-1-概念">1. 概念：</h4>
<p>c++类中声明数据成员时, 加上static关键字声明的成员成为静态数据成员。</p>
<p>普通非 <code>inline</code> 静态数据成员的形式：<em><strong>类内：static 数据类型 变量名;</strong></em> 声明</p>
<p>​			<em><strong>类外：数据类型 类名::变量名=值;</strong></em>  / <em><strong>数据类型 类名::变量名;</strong></em> 定义和初始化</p>
<span id="2-特点" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-2-特点">2. 特点：</h4>
<ol>
<li>静态数据成员遵守 <code>public</code>、<code>protected</code>、<code>private</code> 访问规则。普通非 <code>inline</code> 静态成员的类内声明通常不是定义，需要定义时写在命名空间作用域中。类外定义可以不写显式初值，例如 <code>int Point::pointcounter;</code>，静态存储期的整数会零初始化。非 <code>volatile</code> 的 <code>const</code> 整数或枚举静态成员可以在类内给出常量初值；如果发生 odr-use（例如取地址），仍需类外定义，并且不重复初值。从 C++17 起，<code>inline static int count = 0;</code> 可以直接在类内定义和初始化。</li>
<li>本文未使用 <code>thread_local</code> 的静态数据成员只有一份存储，由同类对象共享。它具有静态存储期，独立于各个对象；即使尚未创建该类对象，也可以按访问权限使用。它仍是类的成员，具有类作用域和成员访问控制。</li>
<li>可以通过对象访问静态数据成员，也可以通过<strong>类名::静态数据成员</strong>的方法去访问。</li>
<li>静态数据成员可以作为成员函数的默认参数值，其类型可以是所属类的类型（普通数据成员均不可）。</li>
<li>常成员函数可以修改非 <code>const</code> 静态数据成员，因为它们不属于 <code>this</code> 所指对象的子对象；声明为 <code>const</code> 的静态数据成员仍不能修改。</li>
<li><code>sizeof</code> 计算对象大小时不会把静态数据成员算进去，但类对象大小也不等于非静态成员大小的简单求和，还需要考虑对齐、填充和基类等因素。</li>
</ol>
<p>静态成员的声明、定义和类内初始化条件见 <a href="https://eel.is/c++draft/class.static.data" rel="noopener noreferrer">C++ 标准草案</a>，C++17 的 <code>inline</code> 变量见 <a href="https://gcc.gnu.org/projects/cxx-status.html#cxx17" rel="noopener noreferrer">GCC 标准支持表</a>，对象大小规则见 <a href="https://eel.is/c++draft/expr.sizeof#2" rel="noopener noreferrer"><code>sizeof</code></a>。</p>

<span id="三静态成员函数" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-三静态成员函数">（三）静态成员函数：</h3>
<h4 id="section-1-概念-1">1. 概念：</h4>
<p>静态成员函数是指用static修饰的成员函数。</p>
<p>静态成员函数可以组织与类相关、但不依赖某个特定对象的操作，例如处理静态数据成员。</p>
<p>形式：<em><strong>static 返回类型 函数名( 参数表) { 函数体 }</strong></em></p>
<span id="2特点" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-2特点">2.特点：</h4>
<ol>
<li>静态成员函数没有 <code>this</code> 指针，不会隐式关联某个对象；它仍是类的成员函数，遵守类作用域和访问控制。</li>
<li>静态成员函数可以直接使用可访问的静态成员。访问非静态成员时，需要明确给出对象、引用或指针，因为函数本身没有 <code>this</code>。</li>
<li>静态成员函数的实现可以在类体内，也可以在类体外。</li>
<li>静态成员函数的调用可以通过类，也可以通过对象，且<strong>无需对象就可以调用静态成员函数</strong>。</li>
<li>例如，静态成员函数内部可以用 <code>obj.x</code> 或 <code>ptr->x</code> 访问对象的非静态成员；作为本类成员函数，它也可以这样访问本类对象的私有成员。</li>
</ol>
<p>以上 <code>this</code> 限制见 <a href="https://eel.is/c++draft/class.static.mfct" rel="noopener noreferrer">静态成员函数规则</a>。</p>
