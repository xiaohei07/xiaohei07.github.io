<span id="一汉诺塔问题" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-一汉诺塔问题">（一）汉诺塔问题：</h3>
<span id="1-问题" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-1-问题">1. 问题：</h4>
<p>汉诺塔问题是一个经典的问题。该问题是在一块铜板装置上，有三根杆(编号A、B、C)，在A杆自下而上、由大到小按顺序放置n个盘子。</p>
<p>问题的目标是把A杆上的金盘全部移到C杆上，并仍保持原有顺序叠好。</p>
<p>操作规则：每次只能移动一个盘子，并且在移动过程中三根杆上都始终保持大盘在下，小盘在上，操作过程中盘子可以置于A、B、C任一杆上。</p>
<span id="2-基本思想" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-2-基本思想">2. 基本思想：</h4>
<p>假设共需要移动A柱的n个盘子。</p>
<p>首先考虑最大的盘子，如果移到B柱，未来仍需要移动到C柱，等于直接从A柱移到C柱，所以可以省略无用的这一步，直接从A->C，那么其他的n-1个盘子应当为其腾出空间移动，移动至B柱，否则此步无法进行。等待最大的移动到C柱之后将这n-1个盘子其移动到C柱，而此过程可以看作新的汉诺塔问题：从B柱到C柱移动n-1个盘子，问题性质不变.......直到只剩最小的盘子，此时可以直接移到C柱，问题的解是显然的。</p>
<p>由上面的过程和性质，汉诺塔问题显然可以分治解决，将一个复杂的N问题一步步分解为子问题，直到变成1问题，1问题的解是直观的，再逐步合并子问题，得到原问题的解。</p>
<span id="3-时间复杂度" class="legacy-anchor" aria-hidden="true"></span><h4 id="section-3-时间复杂度">3. 时间复杂度：</h4>
<p>设盘子个数为n时，需要T(n)步，把A柱子n-1个盘子移到B柱子，需要T(n-1)步，而A柱子最后一个盘子移到C柱子1步，B柱子上n-1个盘子移到C柱子上T(n-1)步。
进而可得公式：</p>
<p><code>T(n) = 2T(n-1) + 1</code>，<code>T(1) = 1</code>。</p>
<p>因此移动次数为 <code>2^n - 1</code>，时间复杂度为 <code>Θ(2^n)</code>。下面的函数要求 <code>n >= 1</code>；主函数传入 16，注释仅列出原稿中 <code>n = 4</code> 的历史输出。</p>

<span id="二有序二分查找问题" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-二有序二分查找问题">（二）有序二分查找问题：</h3>
<h4 id="section-1-问题-1">1. 问题：</h4>
<p>在某一个有序序列内查找某个值是否存在。</p>
<h4 id="section-2-基本思想-1">2. 基本思想：</h4>
<p>二分查找算法，也称折半搜索算法、对数搜索算法，是一种在有序数组中查找某一特定元素的分治搜索算法。</p>
<p>下面只讨论已经按升序排列、支持随机访问的数组。若输入尚未有序，应另计排序的成本。</p>
<p>二分查找算法的搜索过程从数组的中间元素开始，如果中间元素正好是要查找的元素，则搜索过程结束；如果某一特定元素大于或者小于中间元素，则在数组大于或小于中间元素的那一半中查找，而且跟开始一样从中间元素开始比较。如果在某一步骤数组为空，则代表找不到。这种搜索算法每一次比较都使搜索范围缩小一半。</p>
<p>我们假设查询对象是一个名为array的数组，且为升序排序，使用变量left表示查找范围的左边界，right表示右边界，mid表示中间位置(向下取整)，value为要查找的元素。二分查找算法的实现过程如下：</p>
<ol>
<li>
<p>初始化数组array的值(有序升序排序)。</p>
<p>left=0，指向array[ ]的第一个元素。</p>
<p>right=array.length-1，指向数组array[ ]的最后一个元素。</p>
<p>进入循环后计算 <code>mid = left + (right-left) / 2</code>，指向区间中点并向下取整，避免直接相加导致溢出。</p>
</li>
<li>
<p>判定 left&#x3C;=right是否成立，如果不成立，算法结束，说明该列表中没有指定元素。</p>
</li>
<li>
<p>如果2中判断成立，比较value和 array[mid] 。如果 value == array[mid] ，搜索成功，算法结束，返回相对应的位置或者布尔值；如果 value >array[mid] ，令 left=mid+1，并在下一轮更新中点，继续在数组的后半部分进行搜索，重复2和3步即可；如果 value &#x3C;array[mid] ，令 right=mid-1，同样更新mid，继续在数组的前半部分进行搜索，重复2和3步即可。</p>
</li>
</ol>
<h4 id="section-3-时间复杂度-1">3. 时间复杂度：</h4>
<p>二分查找每次会使得查找区间缩小一半，从n到n/2，n/4，…，n/2^k。</p>
<p>k为循环的次数，最坏情况下k次二分之后在区间长度为1时找到了需要的元素。</p>
<p>当 <code>n >= 1</code> 时，区间长度减半约 <code>log₂n</code> 次后至多剩一个元素，查找过程需要 <code>O(log n)</code> 时间。迭代实现仅维护三个下标，额外空间为 <code>O(1)</code>；输入数组占用的空间和预先排序的成本另计。</p>
<p>下面用常量引用传入数组，避免原稿按值传参带来的 <code>O(n)</code> 拷贝。数组长度须能用 <code>int</code> 表示；空数组直接返回 -1，未命中也返回 -1，有重复值时返回其中一个匹配位置。</p>

<h3 id="section-三线性时间选择">（三）线性时间选择：</h3>
<h4 id="section-1-问题-2">1. 问题：</h4>
<p>给定线性序集中n个元素（元素不重复）和一个整数k，1≤k≤n，要求找出这n个元素中第k小的元素。</p>
<h4 id="section-2-基本思想-2">2. 基本思想：</h4>
<p>使用线性时间选择算法Select()，此方法实际上是从快速排序方法上改进而来的。</p>
<p>这里求的是当前区间 <code>[p,r]</code> 内第 <code>k</code> 小的值，<code>k</code> 从 1 开始计数，并非原数组的下标。下面沿用原稿“元素互不相同”的前提。区间不超过 75 个元素时直接排序；75 只是本例的小规模处理阈值，不是算法的适用下限。</p>
<p>步骤为：</p>
<ol>
<li>
<p>每五个元素组成一组，把完整组的第三小元素交换到区间前端。令 <code>m = floor(n/5)</code>；末尾不足五个的元素暂不参与选基准，仍参与后面的全区间划分。</p>
</li>
<li>
<p>在这 <code>m</code> 个中位数中递归求第 <code>m/2+1</code> 小的值（整数除法），作为划分基准；<code>m</code> 为偶数时选择较大的中位数。</p>
</li>
<li>
<p>把基准移到区间首部，再用有边界检查的双指针划分整个区间。最终基准位于 <code>q</code>，左边的值小于它，右边的值大于它。</p>
<img src="https://s1.ax1x.com/2023/04/05/pp57e58.png" alt="划分基准示意图" width="547" height="271" loading="lazy" decoding="async" referrerpolicy="no-referrer">
</li>
<li>
<p>基准在当前区间的排名是 <code>rank = q-p+1</code>。若 <code>k == rank</code>，直接返回它；若 <code>k &#x3C; rank</code>，在左区间查第 <code>k</code> 小；否则在右区间查第 <code>k-rank</code> 小。</p>
</li>
</ol>
<h4 id="section-3-时间复杂度-2">3. 时间复杂度：</h4>
<p>五元分组保证基准两侧各至少有 <code>3n/10-O(1)</code> 个元素，因此查找排名时至多递归处理 <code>7n/10+O(1)</code> 个元素。还需计入递归选择中位数的 <code>T(floor(n/5))</code>，不能只写划分后的一次递归。</p>
<p>递推上界为 <code>T(n) &#x3C;= T(floor(n/5)) + T(7n/10+O(1)) + O(n)</code>。两项递归规模的主要部分相加为 <code>9n/10</code>，可用代入法证明 <code>T(n)=O(n)</code>。这不是等规模子问题，不能直接套用上一篇列出的简化主定理。</p>
<p>排名分支和递推依据见 <a href="https://courses.csail.mit.edu/6.046/spring03/handouts/lec6.pdf" rel="noopener noreferrer">MIT 6.046 Lecture 6</a> 与 <a href="https://web.stanford.edu/class/archive/cs/cs161/cs161.1168/lecture5.pdf" rel="noopener noreferrer">Stanford CS161 Lecture 5</a>。</p>
