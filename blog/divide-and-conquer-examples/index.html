（一）汉诺塔问题：

1. 问题：

汉诺塔问题是一个经典的问题。该问题是在一块铜板装置上，有三根杆(编号A、B、C)，在A杆自下而上、由大到小按顺序放置n个盘子。

问题的目标是把A杆上的金盘全部移到C杆上，并仍保持原有顺序叠好。

操作规则：每次只能移动一个盘子，并且在移动过程中三根杆上都始终保持大盘在下，小盘在上，操作过程中盘子可以置于A、B、C任一杆上。

2. 基本思想：

假设共需要移动A柱的n个盘子。

首先考虑最大的盘子，如果移到B柱，未来仍需要移动到C柱，等于直接从A柱移到C柱，所以可以省略无用的这一步，直接从A->C，那么其他的n-1个盘子应当为其腾出空间移动，移动至B柱，否则此步无法进行。等待最大的移动到C柱之后将这n-1个盘子其移动到C柱，而此过程可以看作新的汉诺塔问题：从B柱到C柱移动n-1个盘子，问题性质不变.......直到只剩最小的盘子，此时可以直接移到C柱，问题的解是显然的。

由上面的过程和性质，汉诺塔问题显然可以分治解决，将一个复杂的N问题一步步分解为子问题，直到变成1问题，1问题的解是直观的，再逐步合并子问题，得到原问题的解。

3. 时间复杂度：

设盘子个数为n时，需要T(n)步，把A柱子n-1个盘子移到B柱子，需要T(n-1)步，而A柱子最后一个盘子移到C柱子1步，B柱子上n-1个盘子移到C柱子上T(n-1)步。 进而可得公式：

T(n) = 2T(n-1) + 1，T(1) = 1。

因此移动次数为 2^n - 1，时间复杂度为 Θ(2^n)。下面的函数要求 n >= 1；主函数传入 16，注释仅列出原稿中 n = 4 的历史输出。

4. 代码：

text
#include<iostream>
using namespace std;
//b为辅助的那根柱子，a为盘子所在的柱子，c为要移动到的柱子
//盘子顺序由小到大排序，最小的为第一个盘子
void tower_of_Hanoi(int n, char a, char b, char c)
{
	if (n == 1)
	{
		cout << "第1个盘子由" << a << "->" << c << endl;
	}
	else
	{
		tower_of_Hanoi(n - 1, a, c, b);   //将A柱的n-1个盘子借助C移向B
		cout << "第" << n << "个盘子由" << a << "->" << c << endl;   //将A柱剩下的最大的盘子移向C
		tower_of_Hanoi(n - 1, b, a, c);   //将B柱的n-1个盘子借助A移向C
	}
	return;
}
int main()
{
	tower_of_Hanoi(16,'A','B','C');
	return 0;
}

（二）有序二分查找问题：

1. 问题：

在某一个有序序列内查找某个值是否存在。

2. 基本思想：

二分查找算法，也称折半搜索算法、对数搜索算法，是一种在有序数组中查找某一特定元素的分治搜索算法。

下面只讨论已经按升序排列、支持随机访问的数组。若输入尚未有序，应另计排序的成本。

二分查找算法的搜索过程从数组的中间元素开始，如果中间元素正好是要查找的元素，则搜索过程结束；如果某一特定元素大于或者小于中间元素，则在数组大于或小于中间元素的那一半中查找，而且跟开始一样从中间元素开始比较。如果在某一步骤数组为空，则代表找不到。这种搜索算法每一次比较都使搜索范围缩小一半。

我们假设查询对象是一个名为array的数组，且为升序排序，使用变量left表示查找范围的左边界，right表示右边界，mid表示中间位置(向下取整)，value为要查找的元素。二分查找算法的实现过程如下：

  1. 初始化数组array的值(有序升序排序)。

    left=0，指向array[ ]的第一个元素。

    right=array.length-1，指向数组array[ ]的最后一个元素。

    进入循环后计算 mid = left + (right-left) / 2，指向区间中点并向下取整，避免直接相加导致溢出。

  2. 判定 left<=right是否成立，如果不成立，算法结束，说明该列表中没有指定元素。

  3. 如果2中判断成立，比较value和 array[mid] 。如果 value == array[mid] ，搜索成功，算法结束，返回相对应的位置或者布尔值；如果 value >array[mid] ，令 left=mid+1，并在下一轮更新中点，继续在数组的后半部分进行搜索，重复2和3步即可；如果 value <array[mid] ，令 right=mid-1，同样更新mid，继续在数组的前半部分进行搜索，重复2和3步即可。

3. 时间复杂度：

二分查找每次会使得查找区间缩小一半，从n到n/2，n/4，…，n/2^k。

k为循环的次数，最坏情况下k次二分之后在区间长度为1时找到了需要的元素。

当 n >= 1 时，区间长度减半约 log₂n 次后至多剩一个元素，查找过程需要 O(log n) 时间。迭代实现仅维护三个下标，额外空间为 O(1)；输入数组占用的空间和预先排序的成本另计。

下面用常量引用传入数组，避免原稿按值传参带来的 O(n) 拷贝。数组长度须能用 int 表示；空数组直接返回 -1，未命中也返回 -1，有重复值时返回其中一个匹配位置。

4. 代码：

text
#include<iostream>
#include <ctime>
#include <random>
#include<vector>
#include<algorithm>
#include<limits>
#include<stdexcept>
using namespace std;
//用随机数测试二分查找（小范围，少数量）
int search_binary(const vector<int>& v, int value)
{
	if (v.size() > static_cast<size_t>(numeric_limits<int>::max()))
		throw length_error("array too large for int indices");
	int left = 0;
	int right = static_cast<int>(v.size()) - 1;
	while (left <= right)
	{
		int mid = left + (right - left) / 2;
		if (v[mid] == value)
		{
			return mid;
		}
		else if (value < v[mid])
		{
			right = mid - 1;
		}
		else
		{
			left = mid + 1;
		}
	}
	return -1;
}
int main()
{
	std::default_random_engine e;
	std::uniform_int_distribution<int> u(1, 200);
	e.seed(time(0));
	vector<int>v;
	for (int i = 0; i < 50; i++) 
	{
		int j = u(e);
		v.push_back(j); 
	}
	sort(v.begin(),v.end());
	for (int i = 0; i < 10; i++) {
		cout << search_binary(v, 50 + i) << endl;;
	}
	return 0;
}
//运行结果随机

（三）线性时间选择：

1. 问题：

给定线性序集中n个元素（元素不重复）和一个整数k，1≤k≤n，要求找出这n个元素中第k小的元素。

2. 基本思想：

使用线性时间选择算法Select()，此方法实际上是从快速排序方法上改进而来的。

这里求的是当前区间 [p,r] 内第 k 小的值，k 从 1 开始计数，并非原数组的下标。下面沿用原稿“元素互不相同”的前提。区间不超过 75 个元素时直接排序；75 只是本例的小规模处理阈值，不是算法的适用下限。

步骤为：

  1. 每五个元素组成一组，把完整组的第三小元素交换到区间前端。令 m = floor(n/5)；末尾不足五个的元素暂不参与选基准，仍参与后面的全区间划分。

  2. 在这 m 个中位数中递归求第 m/2+1 小的值（整数除法），作为划分基准；m 为偶数时选择较大的中位数。

  3. 把基准移到区间首部，再用有边界检查的双指针划分整个区间。最终基准位于 q，左边的值小于它，右边的值大于它。

  4. 基准在当前区间的排名是 rank = q-p+1。若 k == rank，直接返回它；若 k < rank，在左区间查第 k 小；否则在右区间查第 k-rank 小。

3. 时间复杂度：

五元分组保证基准两侧各至少有 3n/10-O(1) 个元素，因此查找排名时至多递归处理 7n/10+O(1) 个元素。还需计入递归选择中位数的 T(floor(n/5))，不能只写划分后的一次递归。

递推上界为 T(n) <= T(floor(n/5)) + T(7n/10+O(1)) + O(n)。两项递归规模的主要部分相加为 9n/10，可用代入法证明 T(n)=O(n)。这不是等规模子问题，不能直接套用上一篇列出的简化主定理。

排名分支和递推依据见 MIT 6.046 Lecture 6 与 Stanford CS161 Lecture 5。

4. 代码：

以下为本次修正后的代码。它会原地调整 [p,r]；要求数组长度可用 int 表示，且元素互不相同。无效区间或排名抛出异常。

cpp
#include<iostream>
#include<vector>
#include<algorithm>
#include<random>
#include<stdexcept>
using namespace std;
//直接交换排序，用于固定大小的基例：
void bubbleSort(vector<int>&a, int p, int r)
{
	for (int i = p; i < r; i++)
	{
		for (int j = i + 1; j <= r; j++)
		{
			if (a[j] < a[i])
			swap(a[i], a[j]);
		}
	}
}
//根据划分元素调整容器元素的位置，返回划分元素对应位置。
int Partition(vector<int> &a, int p, int r, int val)
{
	int pos=p;
	for (int q = p; q <= r; q++)
	{
		if (a[q] == val)
		{
			pos = q;
			break;
		}
	}
	swap(a[p], a[pos]);
	int midmidpos;
	int i = p, j = r + 1, midmid = a[p];
	while (1)
	{
		while (j > p && a[--j] > midmid);
		while (i < r && a[++i] < midmid);
		if (i >= j) { break; }
		swap(a[i], a[j]);
	}
	a[p] = a[j];
	a[j] = midmid;
	midmidpos = j;
	return midmidpos;
}

int Select(vector<int> &a, int p, int r, int k)
{
	if (p < 0 || r < p || static_cast<size_t>(r) >= a.size() || k < 1 || k > r - p + 1)
		throw out_of_range("invalid selection range or rank");
	if (r - p < 75)
	{
		bubbleSort(a, p, r);
		return a[p + k - 1];
	}
	//找完整五元组的中位数；不足五个的尾组留待划分
	for (int i = 0; i <= (r - p - 4) / 5; i++) //把每个完整组的中位数交换到区间前端
	{
		int s = p + 5 * i, t = s + 4;
		for (int j = 0; j < 3; j++) //冒泡排序，从后开始排，结果使得后三个数是排好顺序的（递增）
		{
			for (int n = s; n < t - j; n++)
			{
				if (a[n] > a[n + 1])
					swap(a[n+1], a[n]);
			}
		}
		swap(a[p + i], a[s + 2]);//交换每组中的中位数到前面
	}
	int m = (r - p + 1) / 5;
	int midmid = Select(a, p, p + m - 1, m / 2 + 1);
	int midmidpos = Partition(a, p, r, midmid);
	int rank = midmidpos - p + 1;
	if (k == rank) return a[midmidpos];
	if (k < rank) return Select(a, p, midmidpos - 1, k);
	return Select(a, midmidpos + 1, r, k - rank);
}
int main()
{
	vector<int> a;
	for (int i = 1; i <= 1000; ++i) a.push_back(i);
	mt19937 engine(20261017);
	shuffle(a.begin(), a.end(), engine);
	// 在完整区间内查询第1至15小；每次复制，便于独立展示。
	for (int k = 1; k <= 15; ++k)
	{
		vector<int> aa = a;
		cout << "第" << k << "小的数是:" << Select(aa, 0, 999, k) << endl;
	}
	return 0;
}
// 对这组1至1000的输入，第k小的值应当为k；旧随机输出已移除。
