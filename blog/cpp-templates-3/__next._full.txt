<span id="一非类型模板参数通常不应用于函数模版中" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-一非类型模板参数通常不应用于函数模版中">（一）非类型模板参数（通常不应用于函数模版中）：</h3>
<ul>
<li>
<p>模板的非类型形参是内置类型形参，模板参数不是一个类型而是一个具体的值，且值是常量表达式，因此调用非类型模板形参的实参必须是一个常量表达式（因此模板代码不能修改参数的值，也不能使用参数的地址）。</p>
<p>例如template&#x3C;class T, int a> class B{}; 其中int a就是非类型的模板形参。</p>
<p>通常能被传入的常量表达式包括全局变量的地址或引用，全局对象的地址或引用const类型变量，sizeof的表达式的结果以及const int 整型变量。</p>
</li>
<li>
<p>形参只能是整型，枚举，指针和引用，如double，string等是不可以的，但是可以使用double&#x26;或者string*等类型是允许的。</p>
</li>
<li>
<p>当一个模板被实例化时，非类型参数被一个用户提供的或者编译器推断出的值所代替。正因为模板在编译阶段编译器为我们生成一个对应的版本，所以其值应该能够编译时确定，那么他应该是一个常量或者常量表达式。</p>
</li>
<li>
<p>非类型模板形参的形参和实参间所允许的转换</p>
<ul>
<li>允许从数组到指针，从函数到指针的转换。如：template &#x3C;int *a> class A{}; int b[1]; A&#x3C;b> m;即数组到指针的转换。</li>
<li>const修饰符的转换。如：template&#x3C;const int *a> class A{}; int b; A&#x3C;&#x26;b> m; 即从int *到const int *的转换。</li>
<li>提升转换。如：template&#x3C;int a> class A{}; const short b=2; A&#x3C;b> m; 即从short到int的提升转换。</li>
<li>整值转换。如：template&#x3C;unsigned int a> class A{}; A&#x3C;3> m; 即从int 到unsigned int的转换。</li>
<li>常规转换。略。</li>
</ul>
</li>
</ul>

<span id="二默认模板类型形参" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-二默认模板类型形参">（二）默认模板类型形参：</h3>
<p>在c++11新规则中，可以为类模板或者函数模版的类型形参提供默认值。</p>
<p>形式为：<em><strong>template&#x3C;class T1, class T2, ... , class Tk=默认类型 , ... , class Tn=默认类型 > class 类名{ 类体 };</strong></em></p>
<p><em><strong>or template&#x3C;class T1 =默认类型 , class T2, ... , class Tk=默认类型 , ... , class Tn> 返回类型 类型名(形参列表){函数体}</strong></em></p>
<p>类模版为多个默认模版参数声明指定默认值时，必须遵照“从右往左”的规则进行指定。</p>
<p>函数模版不需要遵循此规则，可以任意指定默认值。</p>
<p>函数模板的参数推导规则简单来说就是：能够从函数实参中推导出类型的话，那么默认模版参数就不会被使用，否则使用默认模版参数。</p>
<p>因此，函数模版如果需要提供默认类型，因为其形参列表是从右往左给出默认值的，所以只有其默认类型也是从右往左给出且与值的类型匹配（也就是不会出现不匹配情况）、值的个数匹配，才是有效的默认类型。</p>

<span id="三模版的特化" class="legacy-anchor" aria-hidden="true"></span><h3 id="section-三模版的特化">（三）模版的特化：</h3>
<p>模版的特化是模版参数在某种特定类型下的具体实现，是对单一模版提供的一个特殊实例，它将一个或多个模版参数绑定到特定的类型或值上。</p>
<p>通常情况下，使用模板可以实现一些与类型无关的代码，但对于一些特殊类型的可能会得到一些错误的结果，比如字符串不能进行比较，此时就需要特化出一个专门用于字符串的模版参数。</p>
<p>特化分为函数模版特化和类模版特化：</p>
<ul>
<li>
<p>函数模板特化：</p>
<p>必须要先有一个基础的函数模板，且使用特换模板函数时格式有要求：</p>
<ol>
<li>关键字template后面接一对空的尖括号&#x3C;>。</li>
<li>函数名&#x3C;特化类型>（特化类型 参数1， 特化类型 参数2 , …） 在函数名后跟&#x3C;>其中写要特化的类型。</li>
</ol>
<p>函数形参表必须要和模板函数的基础参数类型完全相同，如果不同编译器可能会报一些奇怪的错误。</p>
<p>（实际上，此为全特化，c++11中，函数模版也可以进行偏特化的部分特化相似操作，但实际上这是一种重载，会导致函数有多个匹配，此时无法区分；不能进行偏特化的部分限制）</p>

<li>
<p>类模版特化：</p>
<p>分为全特化和偏特化：</p>
<ul>
<li>
<p>全特化：将模版参数类型中所有的参数都确定化。</p>
<p>全特化的优先级比偏特化要高。</p>
</li>
<li>
<p>偏特化：对于模版的类型进行限制。</p>
<p>偏特化有两种表现方式：</p>
<ul>
<li>部分特化：将模版参数表中的一部分参数特化。</li>
<li>对于模版类型进行进一步的限制。（如必须特化为指针类型、引用类型）</li>
</ul>
</li>
</ul>
