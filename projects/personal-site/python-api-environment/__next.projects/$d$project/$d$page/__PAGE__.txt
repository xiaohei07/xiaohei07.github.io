2f:T1f79,<p>以前运行Python脚本，通常是给它一个输入，执行完就退出。Web后端需要持续等待请求：读者发来数据，程序检查并处理，再返回结果。FastAPI负责组织接口，Uvicorn负责运行这个Web应用，两者需要配合使用。</p>
<span id="section-一先把解释器与依赖环境确定下来" class="legacy-anchor" aria-hidden="true"></span><span id="section-先把解释器与依赖环境确定下来" class="legacy-anchor" aria-hidden="true"></span><h2 id="section-一python解释器虚拟环境与依赖锁文件">一、Python解释器、虚拟环境与依赖锁文件</h2>
<p>Python解释器执行代码，<strong>虚拟环境隔离项目依赖</strong>。本站使用独立<code>.venv</code>，避免为了升级某个库改变其他Python项目。<code>requirements.txt</code>描述允许的依赖范围，<code>requirements.lock.txt</code>则记录项目使用的精确版本，便于在另一个环境中安装同一组依赖。</p>
<p>下面是在Windows练习目录中的示意命令。<code>&#x3C;已有Python解释器路径></code>需要换成自己已经安装且可用的解释器，不能照抄尖括号：</p>
<div class="code-block"><div class="code-toolbar"><span>powershell</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code class="hljs language-powershell">&#x26; '&#x3C;已有Python解释器路径>' -m venv .venv
&#x26; .\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
</code></pre></div>
<p><code>python -m pip</code>明确让该解释器运行pip，有助于避免“包装到了另一个环境，当前程序仍导入失败”。已有本站环境不需要再次创建。虚拟环境并不隔离操作系统权限，也不是安全沙箱，基本机制见<a href="https://docs.python.org/3/library/venv.html" rel="noopener noreferrer">Python venv文档</a>。</p>
<span id="section-二最小接口怎样写" class="legacy-anchor" aria-hidden="true"></span><span id="section-最小接口怎样写" class="legacy-anchor" aria-hidden="true"></span><h2 id="section-二最小fastapi接口的定义与本地运行">二、最小FastAPI接口的定义与本地运行</h2>
<div class="code-block"><div class="code-toolbar"><span>python</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code class="hljs language-python"><span class="hljs-comment"># lesson_api.py：独立教学示例</span>
<span class="hljs-keyword">from</span> fastapi <span class="hljs-keyword">import</span> FastAPI

app = FastAPI()

<span class="hljs-meta">@app.get(<span class="hljs-params"><span class="hljs-string">"/hello"</span></span>)</span>
<span class="hljs-keyword">def</span> <span class="hljs-title function_">hello</span>(<span class="hljs-params">name: <span class="hljs-built_in">str</span> = <span class="hljs-string">"读者"</span></span>):
    <span class="hljs-keyword">return</span> {<span class="hljs-string">"message"</span>: <span class="hljs-string">f"你好，<span class="hljs-subst">{name}</span>"</span>}
</code></pre></div>
<p><code>FastAPI()</code>创建应用对象。<strong>装饰器把GET方法、<code>/hello</code>路径和hello函数关联起来</strong>，请求到达时，框架读取name参数并调用这个函数，再把返回的字典转换成JSON响应。这样，函数仍然负责普通Python数据处理，HTTP参数解析与响应组织则交给框架完成。</p>
<p>在保存该文件的练习目录中，可以用自己的项目解释器运行：</p>
<div class="code-block"><div class="code-toolbar"><span>powershell</span><button type="button" data-copy-code="true" aria-label="复制代码">复制代码</button></div><pre><code class="hljs language-powershell">&#x26; .\.venv\Scripts\python.exe -m uvicorn lesson_api:app --host 127.0.0.1 --port 8010
</code></pre></div>
<p><code>lesson_api:app</code>表示从模块<code>lesson_api</code>取得变量<code>app</code>，8010只是本地教学端口。浏览器访问<code>http://127.0.0.1:8010/hello?name=小黑</code>，按代码预期得到包含问候文字的JSON。这个练习使用8010端口，与本站服务使用的8000端口分开。<a href="https://fastapi.tiangolo.com/tutorial/first-steps/" rel="noopener noreferrer">FastAPI入门</a>介绍了路径操作与自动接口文档。</p>
<span id="section-三路径参数查询参数与请求体怎样选择" class="legacy-anchor" aria-hidden="true"></span><span id="section-路径参数查询参数与请求体怎样选择" class="legacy-anchor" aria-hidden="true"></span><h2 id="section-三路径参数查询参数与json请求体的用途">三、路径参数、查询参数与JSON请求体的用途</h2>
<p><strong>路径参数用于定位资源，查询参数用于筛选和分页，请求体用于承载提交的数据</strong>。例如<code>/feedback/&#x3C;id></code>中的id定位一条反馈，<code>?status=pending&#x26;page=2</code>选择待处理反馈的第2页，JSON请求体则可以保存反馈类型和消息正文。它们都需要解析，但数据在HTTP请求中的位置和用途各不相同。</p>
<p>本站的提交接口通过<code>payload: FeedbackCreate</code>声明JSON请求体，管理列表通过参数声明读取状态和页码。Pydantic模型会检查字段，FastAPI据此形成接口schema。请求体与模型的对应规则见<a href="https://fastapi.tiangolo.com/tutorial/body/" rel="noopener noreferrer">Request Body</a>。</p>
<p>HTTP方法也表达操作语义：GET用于读取，POST用于创建或执行相应动作，PATCH用于部分更新，DELETE用于删除。方法名不会自动保证权限与幂等，实际行为仍由接口实现。</p>
<span id="section-四uvicornasgi与fastapi怎样衔接" class="legacy-anchor" aria-hidden="true"></span><span id="section-uvicornasgi与fastapi怎样衔接" class="legacy-anchor" aria-hidden="true"></span><h2 id="section-四nginxuvicorn与fastapi的请求调用链">四、Nginx、Uvicorn与FastAPI的请求调用链</h2>
<p>Uvicorn接受网络连接，按ASGI约定把请求信息交给应用。ASGI是服务器与Python异步Web应用之间的接口规范；FastAPI构建在Starlette等组件之上，处理路由、参数、依赖和响应。本站Nginx还位于Uvicorn之前，负责外部入口与代理。接口规范可参考<a href="https://asgi.readthedocs.io/en/latest/introduction.html" rel="noopener noreferrer">ASGI介绍</a>。</p>
<p>可以顺着链条理解：浏览器发HTTP → Nginx转发 → Uvicorn交给应用 → FastAPI找到路由 → 执行业务函数。业务需要保存或读取持久数据时，再通过SQLAlchemy和数据库驱动访问数据库；上面的hello接口只生成问候文字，可以直接返回结果。</p>
<span id="section-五配置与代码为什么要分开" class="legacy-anchor" aria-hidden="true"></span><span id="section-配置与代码为什么要分开" class="legacy-anchor" aria-hidden="true"></span><h2 id="section-五运行配置敏感信息与启动排查">五、运行配置、敏感信息与启动排查</h2>
