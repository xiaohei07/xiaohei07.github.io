同一段对话可以导出为Markdown、TXT、HTML和JSON。Markdown适合继续编辑，TXT便于直接阅读或交给脚本处理，HTML需要在浏览器中显示，JSON则保存程序可以读取的字段。

为了让这些文件使用相同的消息和附件，格式模块接收已经提取好的会话数据，再按各格式规则组织输出。会话中保存标题、消息顺序、角色、正文、思考片段和文件信息；解析器识别内容结构，本项目负责把这些结构与轮次、选项和资源路径连接起来。

一、DOM与Markdown的转换流程

DOM是浏览器组织页面节点的结构，Markdown是带有标题、列表、代码块等标记的文本。提取阶段可能从DOM取得内容，导出阶段又可能需要把Markdown转换成HTML，因此使用了两个方向不同的工具。

  • Turndown把DOM转换为Markdown。本项目在需要从可见页面回退提取时使用它，并通过GFM插件补充表格等扩展语法。GFM是GitHub Flavored Markdown，在基础Markdown上增加了表格、任务列表等约定。
  • marked解析Markdown，并用于后续HTML等输出。它帮助识别标题、段落、列表和代码块，格式模块再根据这些结构生成对应内容。

如果适配器已经取得结构化Markdown，本项目会尽量直接使用，减少重复转换。需要读取DOM时，则先处理网页中的复制按钮、代码卡片及数学节点，让转换工具接收到属于对话正文的内容。

语法树和内容解析的通用思路可以参考内容处理与搜索流程。下面继续展开本项目为了保留代码和文档结构所增加的规则。

二、代码控件清理与动态围栏

网页代码卡片常把语言名称、复制按钮和下载按钮放在代码旁边。如果直接读取整张卡片的文字，这些控件文字也会混入导出结果。因此，本项目先取得语言提示，再在克隆节点中清理控件，最后读取真正的代码内容。语言提示不可靠时，使用text作为代码块类型。

Markdown通过围栏标记代码块，常见形式是三个反引号。如果代码本身就在演示Markdown，其中也可能出现连续三个反引号，外层围栏就需要更长。

本项目先寻找代码中最长的连续反引号段，再生成至少三个、并且比该段多一个反引号的外层围栏。例如，下面的输出使用四个反引号包住内部的三个反引号：

text
````text
这里演示一个Markdown代码块：
```python
print(1)
```
````

外层结束围栏单独占一行，后面保留换行，使下一段能够正常开始。CommonMark围栏规则规定，闭合围栏使用同类字符，长度至少与开始围栏相同。根据代码内容选择长度后，就能把内部围栏完整保留为代码文字。

对于只是看起来像代码的普通文本，提取仍以网页提供的结构为依据，避免在导出过程中改写原有内容。

三、按解析结构调整标题和纯文本

导出文档通常包含会话标题、轮次和角色。回答内部的标题需要根据外层结构适当下沉，例如把回答中的一级标题调整为更深一级。

这一步需要识别真正的Markdown标题。代码块中的shell注释也可能以#开头，若只按行首字符替换，就会改变代码。因此，本项目先通过解析器识别词元，再调整对应结构。

词元是解析器识别出的内容单位，例如标题、段落、列表和代码块。程序知道一段内容属于代码后，就可以保留其中的#和a < b；知道一段属于链接后，生成TXT时也能保留链接地址。标题层级、列表顺序和代码内容因此可以分别处理。

四、HTML净化与公式显示

导出的HTML会在浏览器中打开，对话中的标签、属性和地址也需要经过处理。本项目依次完成Markdown解析、数学排版、HTML净化和资源约束。

其中，转义、净化和CSP分别负责以下工作：

处理方式作用
转义让特殊符号作为文字显示，例如把正文中的尖括号保留为字符
HTML净化移除不允许的标签、属性和地址
CSP内容安全策略约束文档能够执行或加载的资源

公式由KaTeX排版，它会生成HTML、MathML和部分SVG结构。MathML用来描述数学内容，SVG用于表达部分图形。KaTeX通过trust:false限制需要信任的命令；随后，DOMPurify保留公式所需的HTML、MathML和SVG结构，同时移除不允许的活动内容。两步分别在公式排版和HTML净化时执行。

本项目使用锁定版本的KaTeX配置，相关选项可参考KaTeX说明，HTML净化的机制见DOMPurify文档。配置变化后需要重新检查公式显示与安全限制是否同时成立。

五、四类文本输出的组织

格式主要处理适用场景
Markdown组织标题、轮次、角色、代码和资源引用编辑笔记、继续整理
TXT按解析结构保留文字、代码、列表及链接地址阅读、检索和脚本处理
HTML使用marked、KaTeX和DOMPurify生成正文，再加入本地样式用浏览器阅读排版后的文档
JSON输出本扩展定义的消息、资源和选项字段由其他程序继续读取和处理

轮次选择、思考开关和资源映射由各格式共同遵守。例如，关闭思考后，HTML中的相关内容会省略，JSON也会按相同选项处理对应字段。

这些格式复用附件与资源准备结果。Word和PNG还需要处理文档结构与页面绘制，具体过程见Word与PNG的问题修复。
