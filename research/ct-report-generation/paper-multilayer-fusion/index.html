多层视觉特征融合主要涉及两项选择：从视觉编码器的哪些层提取信息，以及在LLM的哪些位置使用这些信息。主论文进一步按外部与内部、直接与模块化划分出四类融合方式，并比较它们的效果。沿着这两项选择，还可以继续阅读特征汇聚、视觉访问和token压缩相关工作。

我对主论文的评价较高，也在笔记中补了比较多的延伸内容。下面先把它自身的实验讲清楚，再分别介绍九项相关工作。它们回答的问题互有关联，具体结构和实验条件则需要各自保留。

外部与内部、直接与模块化的四类融合

位置决定何时融合：外部融合在LLM输入之前完成，内部融合在LLM中间层注入。方式决定怎样融合：直接融合采用加法、拼接或平均等简单操作，模块化融合增加cross-attention等学习模块。

原文Fig.3。蓝线表示经过projector的路径；“直接”仍可能需要维度投影。

类别特征进入位置主要操作需要留意
外部＋直接LLM输入前少量层按通道拼接，多层集合平均后投影通道数、归一化与特征尺度
外部＋模块化LLM输入前由融合器汇总不同视觉层新增参数是否真正改善任务
内部＋直接LLM中间层投影后加入对应视觉位置的隐藏状态注入位置和残差扰动
内部＋模块化LLM中间层添加cross-attention等模块优化难度、参数量和数据需求

本文的内部融合基本按照视觉层与LLM层的对应关系注入，主模型的两者都是24层。因此，视觉特征来源与注入深度在这组实验中有所关联。更换架构时，需要重新对应两侧层数和表示特点，再确定注入位置。

跨阶段代表层与不同层集合的选择

作者根据表示相似性区分早、中、晚三个阶段，再在主实验中选第3、18、23层作为代表。另一组更朴素的方案按比例选择前半、后半或全部层。

名称额外融合的层集合与原始输入的关系
Single{18}原始视觉输入已取第23层
Double{3,18}补入早期和中期表示
Triple{3,18,23}再次使用末期表示，可能重复
Former / Latter / All前半／后半／全部层覆盖更多层，也引入更多冗余或模块

其中，Double表示在原有末期视觉输入之外，额外加入两层特征。它将早期和中期表示补充进来，可以用于检查跨阶段特征的互补性；Triple进一步重复使用末期表示，则适合观察再次加入相近信息后的变化。

对于OCR、空间细节等任务，早期特征可能提供帮助。但浅层不等于永远只有纹理，深层也不等于完全失去位置。表示属性与训练目标、残差连接、读出方式相关，后面的ViT分析正好补充这一点。

延伸一：多层视觉特征的汇聚方法

下面先介绍四篇与特征融合直接相关的工作，依据各论文摘要和官方说明梳理主要机制。可以对照它们提取的特征来源、汇聚方式和输出位置，继续理解多层信息进入LLM的过程。

MMFuser。以较深层、语义已对齐的视觉特征作query，从较浅层与中间层抽取遗漏的细节，再用注意力与残差融合。这样维持输入token的组织方式，同时补充内容。我把它理解为让一个ViT内部的多层信息发挥作用；这些特征来自同一个视觉编码器的不同层。MMFuser原文

LION。一条路径用vision aggregator配合区域级图文任务学习空间细节，另一条路径把图像标签变成高层语义提示。分阶段指令训练与mixture-of-adapters缓解全图任务和区域任务的冲突；soft prompt用于降低不完美标签的直接干扰。阅读时可以把Q-Former、区域聚合器、标签模型与adapter的职责分别列出来，这些模块处理的对象与信息层次并不相同。LION原文

EVLM。结合类似Flamingo的图文cross-attention、多层ViT表示和MoE。视觉作为被访问的信息源，不必让所有视觉token都参与语言侧完整自注意力。进一步对照self-attention与cross-attention中Q/K/V的来源，就能区分视觉进入语言序列，以及语言状态通过注意力读取外部视觉信息这两种方式。EVLM原文

Dense Connector。按token维与通道维，可以把它的三种融合分别理解为：稀疏token整合、稀疏通道整合、密集通道整合。前者把不同层的token整理成序列，后两者主要沿通道聚合；是否增加LLM序列长度由具体实现决定。这个视角也解释了为何简单的多层融合不必附带复杂注意力模块。Dense Connector原文

延伸二：视觉层相似性与模型层间干预

要理解视觉编码器为什么值得取不同层的特征，可以继续看Do Vision Transformers See Like Convolutional Neural Networks?。它分析了ViT与CNN的层间相似性、有效感受野、残差连接，以及CLS和patch token的不同作用。

CKA等工具比较的是样本表示之间的关系，适合检查不同层是否呈现类似结构。ViT中更均匀的跨层相似性，与较早汇聚全局信息和残差传播有关；高层patch仍可能保留位置线索。注意力距离、空间定位热图和去掉skip connection后的变化，可以从不同角度解释这些现象；单独一张相似度热图，还不足以判断某层是否可以删除。ViT与CNN分析原文

这里与主论文相连的推论是：先检查表示阶段，再选互补层，比机械取每隔几层更有依据。推论仍需在自己的视觉编码器上验证，CLIP、DINO和医学3D编码器不必出现同样分段。

Transformer Layers as Painters进一步检查冻结模型中的跳层、重复、逆序、并行与循环并行。部分中层操作的破坏较小，首尾层更敏感；这支持中间层存在一定计算冗余和共享表示空间，但任务、模型与干预范围会影响结果。Transformer Layers as Painters原文

层重排实验说明，部分任务对特定范围的中间层调整具有一定容忍度。具体容忍范围仍取决于模型和任务，因此，可以用它探索计算冗余，再通过相应任务结果检查顺序依赖。

延伸三：长视觉序列的外部访问与token剪枝

mPLUG-Owl3与长视觉输入的处理关系较大，可以展开一点。它把patch特征保留为外部视觉信息，在若干Hyper Attention Transformer Block中让语言状态访问；文本序列中保留图像占位符，避免全部patch都作为普通语言token穿过每一层。mPLUG-Owl3原文

其中几个模块的关系如下：

  • 文本self-attention维持语言上下文；视觉cross-attention以语言状态为query、视觉特征为key/value。
  • 两条注意力路径在Hyper Attention内融合，Adaptive Gate调节视觉与语言信息比例；它与先串联一层独立cross-attention的结构不同。
  • 多图像输入用图像占位位置与MI-RoPE维持图文相对关系，配合因果mask控制哪些视觉信息可被访问。这里的位置是多模态序列位置，不能直接等同于图像二维像素位置。
  • 插入位置和数量也需要一起比较。在对应消融中，稀疏分布的4个HATB优于继续增加块数的部分设置；最终还要看任务，而不是只数模块。

这部分讨论的是mPLUG-Owl3自己的结构和实验条件，与前面的融合主论文分别理解。它给我的启发是：面对很长的视觉输入，可以保留较丰富的外部视觉信息，让语言表示按层访问；代价是额外的cross-attention和位置处理，并非计算成本消失。

FastV从另一端削减成本：先经过若干层让模型形成注意力信息，再保留较重要的视觉token，剪掉后续计算中贡献较小的部分。其中K对应开始筛选的层，R对应筛除比例；这些是速度与性能的可调参数，不能把论文标题中的“二层、半数”当作固定最优值。FastV原文

注意力强弱与信息价值相关，却不是完全等价。早层与深层的注意力分布不同，这也让我联想到视频token压缩与“anchor token”等后续方向。不过这些只是延伸问题，还没有作为可用于CT的方案验证。与Visual Token Sparsity并读，可进一步检查低注意力是否真的意味着可删除。

延伸四：DeepStack的分组视觉token与深度注入

DeepStack把视觉token分组，分批注入不同transformer层，避免把所有高分辨率内容都铺成第一层的长序列。DeepStack-L和DeepStack-V的注入位置不同：前者沿语言模型深度注入，后者沿视觉编码器深度注入，再向语言侧输出视觉表示。DeepStack原文

这里需要与主论文的“视觉多层”区分：DeepStack注入的内容可以来自高分辨率图像分块或不同视觉组，而主论文重点比较同一个视觉编码器不同深度的特征。信息来源与注入位置是两个维度，同样叫内部融合，输入的内容可能不同。

浅层更容易吸收新视觉信息、过晚注入可能干扰已有表示，是这些特定架构和实验下的一种设计判断。它与主论文某些内部直接融合后层更稳定的现象并不必然矛盾：注入内容、残差形式、参数和任务都变了，需要控制条件再比较。

CT任务中的特征融合实验思路

把这些方法联系起来，可以按特征来源、LLM访问位置与后续计算量三个方面比较。MMFuser与Dense Connector主要处理特征汇聚，主论文和DeepStack进一步讨论注入位置，mPLUG-Owl3与FastV则提供了组织长视觉输入和减少后续计算的思路。

如果迁移到CT，我会先固定视觉编码器、训练数据和语言模型，再比较少量跨阶段特征的简单融合；随后才增加器官query、层内访问或token剪枝。小病灶、左右侧、跨切片关系应单独评价。通用VQA平均分提高，可以支持机制探索，但不能替代医学影像任务的证据。
